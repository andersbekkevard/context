# NTNU prosentvurderingsmetoden

Standard percentage-to-letter mapping used for technology subjects (incl. TMA4268). Score is total points as a percentage of the maximum.

| Grade | Percentage |
|-------|------------|
| A | 89–100 |
| B | 77–88  |
| C | 65–76  |
| D | 53–64  |
| E | 41–52  |
| F | 0–40   |

Band widths: A = 12, B = 12, C = 12, D = 12, E = 12, F = 41. C-band midpoint ≈ 70.

## Notes for mock-exam construction

- Boundaries are **advisory**, not mandatory — examiners may deviate.
- When designing a mock exam, allocate points so that a "passing but weak" candidate lands ~41–52 % (E) and a "solid command of curriculum" candidate lands ~65–76 % (C). The mode of a well-calibrated cohort typically sits in the C band.
- A-grade content should require synthesis, edge-case reasoning, or non-obvious derivations — not just more volume of routine work.
- Aim for total points to be a round number (e.g. 100) so percentages map directly without arithmetic.
