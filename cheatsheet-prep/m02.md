# Module 02 — Statistical learning — cheat-sheet candidates

## MUST (would lose meaningful points without this)

- **Bias-variance decomposition (3 terms).** $\mathbb{E}[(y_0-\hat f(x_0))^2] = \sigma^2 + (f(x_0)-\mathbb{E}[\hat f(x_0)])^2 + \mathrm{Var}(\hat f(x_0))$. $\mathbb{E}$ over training set $\mathcal{D}$ and noise $\varepsilon$. Prof's #1 guaranteed exam topic.

- **Derivation skeleton (cross-term kills).** Step 1: substitute $y_0=f+\varepsilon$, expand $(f-\hat f+\varepsilon)^2$; cross term $2\mathbb{E}[(f-\hat f)\varepsilon]=0$ **because $\mathbb{E}[\varepsilon]=0$** (not "independence"); $\mathbb{E}[\varepsilon^2]=\sigma^2$. Step 2: add/subtract $\mathbb{E}[\hat f]$, get $(f-\mathbb{E}\hat f)+(\mathbb{E}\hat f-\hat f)$; cross term $=0$ by LIE ($\mathbb{E}[\mathbb{E}\hat f-\hat f]=0$). Squared bias is **truth-relative**, variance is over training resamples.

- **Why prof rejects "trade-off."** (i) Regularization (ridge/lasso/dropout/etc.) flattens variance curve at small bias cost — bias is **squared**, so small bias buys big variance reduction. (ii) Double descent: past interpolation, both shrink. The decomposition is exact; the U-shape is not a law.

- **Direction-of-effect cheat (flexibility ↑).** Training MSE ↓ always (monotone). Test MSE U-shaped. Bias² ↓. Variance ↑. Irreducible $\sigma^2$ flat. For KNN: flexibility = $1/K$ (inverted knob — small $K$ = high flexibility).

- **CE1.1d T/F traps (all FALSE).** (i) Bias-variance more relevant for prediction than inference — FALSE: inference about $\hat\beta$ uses sampling dist, not pred MSE. (ii) Test MSE $\to 0$ as $n\to\infty$ — FALSE: $\sigma^2$ stays. (iii) Lower bias → better predictions — FALSE: ignores variance. (iv) High $\sigma^2$ → want more flexibility — FALSE: opposite, want low-variance method.

- **Reducible/irreducible split.** $\mathbb{E}[(Y-\hat Y)^2]=(f-\hat f)^2+\mathrm{Var}(\varepsilon)$. Irreducible = noise floor; only better data (lower-noise sensors, missing covariates) reduces it. Classification analogue: Bayes error rate $1-\mathbb{E}[\max_j P(Y=j|X)]$.

- **Covariance-of-linear-transform.** $\mathbf{Z}=C\mathbf{X}\Rightarrow \mathbb{E}(\mathbf{Z})=C\boldsymbol\mu$, $\mathrm{Cov}(\mathbf{Z})=C\boldsymbol\Sigma C^\top$. **Transpose on the RIGHT**, not $C^\top\Sigma C$. Engine for: $\hat\beta$ sampling dist (M3), LDA/QDA discriminants (M4), PCA loadings (M10), contrast tests.

- **$\Sigma\to\rho$ formula.** $\rho_{ij}=\sigma_{ij}/\sqrt{\sigma_i^2\sigma_j^2}=\sigma_{ij}/(\sigma_i\sigma_j)$. **Square-root trap** (CE1.1f): $\Sigma=\begin{pmatrix}9&0.3\\0.3&4\end{pmatrix}\Rightarrow\rho=0.3/\sqrt{36}=0.05$. Distractors: 0.0083 (forgot sqrt), 0.15 ($/2$), 0.10 ($/3$).

- **Zero covariance ≠ independence** in general. **Equivalent only under joint normality.** Covariance captures only **linear** co-variation. Classic T/F trap.

- **MVN density.** $f(\mathbf{x})=(2\pi)^{-p/2}|\Sigma|^{-1/2}\exp(-\tfrac12(\mathbf{x}-\boldsymbol\mu)^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol\mu))$. Exponent = $-\tfrac12 D_M^2$ (Mahalanobis). $|\Sigma|=0$ → density undefined (collinearity / LDA failure).

- **MVN 4 properties.** (1) Contours = ellipsoids centered at $\boldsymbol\mu$, shaped by $\Sigma$. (2) $A\mathbf{X}+\mathbf{b}\sim N(A\boldsymbol\mu+\mathbf{b}, A\Sigma A^\top)$. (3) Marginals normal. (4) **Zero cov ⇒ independence (MVN only).** Also: conditionals normal → linear regression is the exact conditional of joint MVN.

- **Σ-to-contour map (CE1.1g).** $\sigma_x^2=\sigma_y^2,\rho=0$: circle. Unequal vars, $\rho=0$: axis-aligned ellipse, long axis on larger variance. $\rho>0$: tilted up-right. $\rho<0$: tilted up-left. Both: tilted, long axis closer to larger variance.

- **Double descent / benign overfitting.** Past $p\approx n$ (interpolation peak), test MSE drops again, often below classical min. Mechanism: among infinite zero-training-error solutions, optimization picks **minimum-norm interpolator** ($X^+ = X^\top(XX^\top)^{-1}$ when $p>n$; SGD converges to same). Implicit L2 → variance control. Decomposition still exact — bias²+var+$\sigma^2$ sum at every $p$. **Requires truth NOT in function class** (else low-$d$ model already wins).

- **Optimization change across interpolation.** Classical ($p<n$): min RSS + $\lambda\|\beta\|^2$. Over-param ($p\gg n$): $\min\|\beta\|^2$ s.t. $y_i=\mathbf{x}_i^\top\beta\ \forall i$. Fit becomes hard constraint; L2 is sole objective. **"That's the magic of the model"** (prof).

- **KNN regression formula.** $\hat f(x_0)=\tfrac1K\sum_{i\in\mathcal{N}_0}y_i$. K small = wiggly/high-var; $K=n$ = $\bar y$ horizontal line (underfit). Same knob story as classification. **Standardize predictors** (Euclidean is scale-sensitive). Curse of dimensionality kills it.

## NICE (include if there's space)

- **KNN classification.** $\hat P(Y=j|x_0)=\tfrac1K\sum_{i\in\mathcal{N}_0}I(y_i=j)$. Use odd $K$ for binary (ties). Wiggly Bayes boundary → small $K$. Decision regions can be disconnected islands.

- **Σ is symmetric, PSD.** $\mathbf{b}^\top\Sigma\mathbf{b}=\mathrm{Var}(\mathbf{b}^\top\mathbf{X})\geq 0$. Singular $\Sigma$ ⇒ some linear combo deterministic ⇒ MVN density undefined ⇒ LDA $\Sigma^{-1}$ blows up. Same pathology as collinearity ($X^\top X$ singular).

- **$\Sigma$ shortcut.** $\Sigma=\mathbb{E}(\mathbf{XX}^\top)-\boldsymbol\mu\boldsymbol\mu^\top$. $\mathrm{Cov}(X_i,X_i)=\mathrm{Var}(X_i)$ (prof quiz-flagged).

- **Expectation rule for matrices.** $\mathbb{E}(A\mathbf{X}B)=A\,\mathbb{E}(\mathbf{X})\,B$ ($A,B$ constant). Element-wise: only $X_{kl}$ random, $a_{ik},b_{lj}$ pull out.

- **Whitening transform.** $\Sigma^{-1/2}(\mathbf{X}-\boldsymbol\mu)\sim N_p(\mathbf{0},I_p)$. Standard MVN obtained by demean + decorrelate.

- **Mahalanobis & confidence ellipsoid.** $(\mathbf{X}-\boldsymbol\mu)^\top\Sigma^{-1}(\mathbf{X}-\boldsymbol\mu)\sim\chi^2_p$. Ellipsoid $\{x:D_M^2\le\chi^2_p(\alpha)\}$ has prob $1-\alpha$.

- **MVN → regression bridge.** If $(\mathbf{X},Y)$ jointly MVN, $Y|\mathbf{X}=\mathbf{x}$ is normal with mean **linear in $\mathbf{x}$** and constant variance — exactly linear regression. Min-NLL of Gaussian with $\mu=\mathbf{x}^\top\beta$ **is** OLS.

- **Parametric vs nonparametric.** Parametric: assume $f(X)=g(X;\theta)$, finite $\theta$ (linreg, LDA, lasso). Nonparametric: no fixed form (KNN, splines, GAMs, bagging, NN). Nonparametric still has flexibility hyperparams (K, df, $\lambda$); just no structural form. Nonparam can't extrapolate; parametric can (often wrongly).

- **Contrast $C$ for cork.** $\mathbf{X}=(X_N,X_E,X_S,X_W)^\top$; contrasts $N-S$, $E+W$, $(E+W)-(N+S)$: $C=\begin{pmatrix}1&0&-1&0\\0&1&0&1\\-1&1&-1&1\end{pmatrix}$. Then $\mathbb{E}(C\mathbf{X})=C\boldsymbol\mu$, $\mathrm{Cov}=C\Sigma C^\top$. "Contrast" used loosely (not strict sum-to-zero).

- **Curse of dimensionality (KNN-killer).** As $p$ grows, pairwise distances concentrate — "nearest" loses meaning. KNN mechanism breaks. Fix: dim reduction (PCA), "hacky."

- **"Small bias buys big variance" lever.** Bias is squared in MSE → small abs increase contributes little; variance can drop orders of magnitude. Operating principle of every regularizer (ridge, lasso, smoothing splines, dropout, mini-batch SGD's implicit L2, bagging, pruning).
