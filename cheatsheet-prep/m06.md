# Module 06 — Model selection & regularization — cheat-sheet candidates

ISLP ch.6 open-book → most formulas/derivations are LOOKUP. Cheat-sheet earns its space on prof-flagged framings, direction-of-effect traps, book-deltas, and one-line decision rules.

## MUST

- **Ridge vs Lasso, the picture** (the exam figure per [[L14]]):
  - L2 ball = circle, smooth → first contact at interior → shrinks but **never** exact 0 → no var selection.
  - L1 ball = diamond, **corners on axes** → first contact at a corner → **exact zeros** → sparsity.
  - Correlated predictors: ridge **averages** ("socialist"), lasso **picks one, zeros other** ("capitalist", unstable across samples).

- **Objectives** (one line each, both penalize only $\beta_1{:}p$, NOT $\beta_0$):
  - Ridge: $\arg\min \text{RSS} + \lambda\sum\beta_j^2$
  - Lasso: $\arg\min \text{RSS} + \lambda\sum|\beta_j|$
  - Elastic net: $\arg\min \text{RSS} + \lambda\sum\beta_j^2 + \gamma\sum|\beta_j|$ (NOT in ISLP — book-delta §5)

- **Direction-of-effect (λ ↑)**: coeffs shrink → flexibility ↓ → **bias ↑, variance ↓**, test-MSE U-shaped. $\lambda=0$ → OLS; $\lambda\to\infty$ → null (ridge: asymptotic; lasso: all-zero at **finite** λ).

- **Standardize $X$ before ridge / lasso / elastic-net / PCR / PLS / PCA.** Not scale-invariant. Largest-unit predictor would dominate penalty / variance. Intercept not penalized; standardize $X$, center $Y$, $\hat\beta_0=\bar y$. Don't standardize binary dummies. Compute mean/SD on training only.

- **Subset selection counts** (prof drilled, MC bait):
  - Best subset: $2^p$ models — "slow as shit for $p$ big".
  - Forward / backward / hybrid: $1 + p(p+1)/2$ models. ($p=20$: $\sim 10^6$ vs $211$.)

- **Backward stepwise needs $n > p$** (fits full OLS at step 1). **Forward stepwise survives $p > n$** (cap at $\mathcal{M}_0,\dots,\mathcal{M}_{n-1}$). This *exact* contrast was a past-exam MC trap.

- **High-dim ($p>n$) survival table** (canonical T/F):
  - OLS: BREAKS ($X^\top X$ singular; training $R^2=1$ trivially).
  - Backward: BREAKS. Forward: OK (capped). Ridge: OK ($X^\top X+\lambda I$ always invertible). Lasso: OK (active set $\leq n$). Elastic net / PCR / PLS: OK.
  - **"Lasso requires $p<n$" → FALSE** (2024 exam trap).

- **Why CV > AIC/BIC/Cp** (prof's strong opinion; conceptual-only is the rule):
  - AIC/BIC/Cp depend on reliable $\hat\sigma^2$ + distributional/IID assumptions → break when $p\approx n$. CV is assumption-light.
  - One-line comparison: BIC penalty $\log(n)\cdot d$ vs AIC $2d$ → BIC stricter, prefers smaller models. **Don't memorize formulas** — prof excluded.

- **Lasso ⊂ subset-selection-for-free**: one convex fit, no $2^p$ combinatorial search; active set ≤ $\min(n,p)$.

- **PCR one-liner**: standardize → PCA → regress $Y$ on first $M$ PCs (M by CV) → back-transform $\beta_j=\sum_m \theta_m\phi_{jm}$.
  - **PCR ≈ discretized ridge**: both shrink small-eigenvalue directions; PCR hard-truncates, ridge shrinks smoothly.
  - **Critical failure mode**: PCA is *unsupervised* — no guarantee high-$X$-variance directions are predictive of $Y$. PLS fixes this via $\max\text{Cov}(X\phi,Y)$.
  - PCR does **not** do variable selection.

## NICE

- **Ridge closed form** (book-delta §1; ISLP gives it only verbally):
  $\hat\beta^R_\lambda = (X^\top X + \lambda I_p)^{-1}X^\top y$ — the $\lambda I$ is *why* ridge stays unique when $p\geq n$.

- **Ridge bias** (book-delta §1.4): $\mathbb{E}[\hat\beta^R_\lambda]-\beta = -\lambda(X^\top X+\lambda I)^{-1}\beta$. Biased for any $\lambda>0$; variance strictly smaller than OLS in Loewner order.

- **Effective df for ridge** (book-delta §2): $\mathrm{df}(\lambda) = \sum_j \frac{d_j^2}{d_j^2+\lambda}$, slides $p \to 0$ as $\lambda: 0\to\infty$. ISLP only assigns df to lasso (= #nonzero).

- **Per-PC ridge shrinkage** (book-delta §3): $s_j(\lambda) = \frac{\lambda_j^2}{\lambda_j^2+\lambda}$ ($\lambda_j$ eigenvalues of $X^\top X$). Heavy shrinkage on small-eigenvalue PCs. (Notation clash: $\lambda_j$ vs ridge $\lambda$.) ISLP punts to ESL §3.5.

- **PCA fraction-of-variance via eigenvalues** (book-delta §4; NOT in ISLP ch.6, only ch.12): $R^2_\text{PCA} = \frac{\sum_{i=1}^M \lambda_i}{\sum_{j=1}^p \lambda_j}$. Eigenvalue = variance of corresponding PC.

- **Library reparametrization for elastic net**: penalty = $\Lambda[\alpha\sum|\beta_j| + (1-\alpha)\sum\beta_j^2]$. $\alpha=1$ lasso; $\alpha=0$ ridge.

- **1-SE rule** (2024 + 2025 past exams both used it): pick largest $\lambda$ within 1 SE of CV minimum → more parsimony.

- **Trace plot distinguishing feature**: lasso paths *touch zero and stay*; ridge paths *asymptote* but never touch.

- **Refit-on-active-set workflow**: lasso to select, OLS on survivors to remove shrinkage bias.

- **Elastic-net constraint region**: rounded diamond (corners → sparsity + rounded edges → averaging).

- **Multicollinearity in high-dim (slide-verbatim)**: "any variable in the model can be written as a linear combination of all the others." Can never identify truly predictive vars; only ones *correlated with* them. One of many suitable models.

- **Noise features always (eventually) hurt** even with regularization (slide-flagged: lasso fails at $p=2000$ regardless of $\lambda$).
