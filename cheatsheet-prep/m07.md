# Module 07 — Beyond linearity — cheat-sheet candidates

## MUST

- **λ direction trap (smoothing splines, T/F bait):** λ↑ → smoother / straighter / **lower** df_λ / **less** wiggly. Opposite of polynomial degree d and spline knot count K. Same direction as ridge/lasso λ. Limits: λ=0 → interpolates (df→n); λ→∞ → OLS straight line (df→2).
- **Smoothing-spline objective:** min over g of Σ(yᵢ−g(xᵢ))² + λ∫g''(t)² dt. **Second derivative**, squared (2023 Q3d trap: g' is WRONG).
- **Effective df:** df_λ = tr(S_λ); non-integer OK (e.g. 6.8). Linear smoother: ŷ = S·y.
- **DOF table (intercept-counting trap; 2024/2025 both tested):**
  | Method | params incl. int. | excl. int. |
  |---|---|---|
  | Polynomial deg d | d+1 | d |
  | Step, K cuts | K+1 | K |
  | Cubic spline, K knots | **K+4** | K+3 |
  | Natural cubic spline, K int. knots | **K+2** | K+1 |
  | Smoothing spline | tr(S_λ) | tr(S_λ) |
  - 2024 Q2c: NCS, 3 knots → 4 dof (excl. int.)
  - 2025 Q4e(i): `bs(age, knots=4 quantiles)` → 7 dof = K+3 (excl. int.)
  - Rule: if model already has intercept (e.g. inside `gam()`), use excl.-int. column.
- **Cubic-spline truncated-power basis (K knots):** x, x², x³, (x−c₁)³₊, …, (x−c_K)³₊. Continuous through 2nd derivative; 3rd jumps. Fit by OLS.
- **Natural cubic spline:** linear past boundary knots → 2 constraints → K+2 params (vs K+4 for plain cubic). Boundary knots c₀, c_{K+1} add **constraints**, not columns. Use natural splines to tame boundary variance.
- **GAM additivity limit (T/F bait):** y = β₀ + Σⱼ fⱼ(xⱼ); **NO interactions** unless explicit cross-term added. "GAM captures x₁·x₂" → FALSE.
- **GAM dof = sum of component dof, don't double-count the intercept.**
- **Basis-function slogan:** "linear in β, nonlinear in x." Design matrix X has intercept column + basis columns; β̂ = (XᵀX)⁻¹Xᵀy unchanged.

## NICE

- **Natural-cubic-spline basis formula (Exercise 7.3, prof says **apply**, not derive):**
  b₁(x)=x, b_{k+2}(x) = d_k(x) − d_K(x), where d_k(x) = [(x−c_k)³₊ − (x−c_{K+1})³₊] / (c_{K+1}−c_k).
- **GAM fitting regimes:** all-basis-function → plain OLS on stacked X = (1, X₁, …, X_p). With `s()` or `lo()` → **backfitting** (iterative; details OUT of scope, existence IN).
- **Linear-smoother LOOCV shortcut (any linear smoother):**
  RSS_cv = Σ ((yᵢ − ŷᵢ)/(1 − {S}ᵢᵢ))². One fit, free LOOCV. Members: OLS (S=H), ridge, smoothing spline, LOESS.
- **GAM panel interpretation:** each f_j panel = contribution holding others at means. NOT a prediction. Logistic GAM panels are on **log-odds** scale.
- **LOESS span direction:** span↑ → smoother / less flexible (opposite of λ in smoothing splines, same as K in KNN). LOESS = "smoothed KNN."
- **LOESS curse of dimensionality:** dies for p > 3–4 (same as KNN).
- **Smoothing spline = ridge in function space.** S_λ = X(XᵀX + λΩ)⁻¹Xᵀ analog (Ω = curvature matrix); Reinsch algebra OUT.
- **Why splines beat high-deg polynomials:** flexibility from knots, not degree; boundaries stay tame.
- **Cubic spline continuity:** value + 1st + 2nd derivative continuous at knots; 3rd derivative jumps.
- **Column-space punchline (Ex 7.4):** truncated-power basis ≠ B-spline columns, but **same column space → same ŷ**. β̂ basis-dependent; ŷ not.
