# Module 04 — Classification — cheat-sheet candidates

## MUST

### 1. Odds ↔ probability (calculator bait — flagged "will ask")
- $\text{odds} = p/(1-p)$,  $p = \text{odds}/(1+\text{odds})$.
- $\beta_j = \log(\text{OR})$ → one-unit ↑ in $x_j$ multiplies odds by $e^{\beta_j}$ (NOT prob by $\beta_j$).
- **Interaction trap**: with $\beta_{jk} x_j x_k$, OR for $x_j$ is $e^{\beta_j + \beta_{jk} x_k}$ — depends on $x_k$. Report **per group** for sex×$x$.
- Reference-class flip → all signs flip.
- 2025 Q3c: odds=0.37→p≈0.27; p=0.16→odds≈0.19.

### 2. Logistic regression core
- Model: $\eta_i = \beta_0 + \beta^\top x_i$; $p_i = \sigma(\eta_i) = e^{\eta_i}/(1+e^{\eta_i})$; $\text{logit}(p)=\eta$.
- Fit by **MLE, no closed form → Newton-Raphson** (one-liner answer the prof wants).
- Score: $\nabla\ell = X^\top(y-p)$; Hessian $-X^\top W X$, $W=\text{diag}(p_i(1-p_i))$; $\widehat{\text{Var}}(\hat\beta)=(X^\top W X)^{-1}$.
- **Invert sigmoid for $x_j$ threshold**: $x_{0j} = [\text{logit}(p^\star) - \beta_0 - \sum_{k\neq j}\beta_k x_{0k}]/\beta_j$. At $p^\star=0.5$: numerator drops $\log$ term.
- Sign trap (Apr 28, heart-disease): coefficients in `glm` summary read **as effect on log-odds of class 1** — flag your encoding.

### 3. LDA discriminant + decision boundary (prof's flagship exam template, flagged TWICE)
- Assumption: $X|Y=k \sim N(\mu_k, \Sigma)$, **pooled $\Sigma$**, prior $\pi_k$.
- **Multivariate discriminant** (linear in $x$):
  $$\delta_k(x) = x^\top\Sigma^{-1}\mu_k - \tfrac12 \mu_k^\top\Sigma^{-1}\mu_k + \log\pi_k$$
- **1D**: $\delta_k(x) = x\mu_k/\sigma^2 - \mu_k^2/(2\sigma^2) + \log\pi_k$.
- **Posterior recovery** (softmax of $\delta$'s, works for LDA/QDA/NB):
  $$\hat P(Y=k|x) = e^{\delta_k(x)}/\sum_\ell e^{\delta_\ell(x)}$$
- **1D boundary, 2 classes, unequal priors** (closed form ISLP omits):
  $$x = \frac{\mu_1+\mu_2}{2} + \frac{\sigma^2}{\mu_1-\mu_2}\log\frac{\pi_2}{\pi_1}$$
- **Pooled covariance estimator** ($p>1$, ISLP only writes 1D):
  $$\hat\Sigma = \frac{1}{n-K}\sum_k\sum_{i:y_i=k}(x_i-\hat\mu_k)(x_i-\hat\mu_k)^\top$$

### 4. LDA boundary derivation — 5-step procedural template
Given $\mu_A, \mu_B, \Sigma, \pi_A, \pi_B$ in 2D:
1. Invert $\Sigma$ by hand.
2. Cross-term vector $v = \Sigma^{-1}(\mu_A - \mu_B)$ → x-coefficients of boundary.
3. Constant $c = -\tfrac12\mu_A^\top\Sigma^{-1}\mu_A + \tfrac12\mu_B^\top\Sigma^{-1}\mu_B + \log(\pi_A/\pi_B)$.
4. Boundary: $v^\top x + c = 0$.
5. In 2D solve for $x_2 = $ (linear in $x_1$).
- **Trap**: boundary normal is $\Sigma^{-1}(\mu_A-\mu_B)$, **not** $\mu_A-\mu_B$. Only equal if $\Sigma \propto I$.
- **Prior shift direction**: ↑ $\pi_k$ moves boundary **away from** class $k$ (more area = class $k$).
- Verify worked example: $\mu_A=(1,1), \mu_B=(3,3), \Sigma=2I, \pi$ equal → $x_2 = 4 - x_1$.

### 5. QDA discriminant — "where does the quadratic come from?" (flagged)
- Drop pooling: $\Sigma_k$ per class → $-\tfrac12 x^\top\Sigma_k^{-1}x$ no longer cancels across $k$ → quadratic survives.
- **Compact form** (memorize this one):
  $$\delta_k(x) = -\tfrac12(x-\mu_k)^\top\Sigma_k^{-1}(x-\mu_k) - \tfrac12\log|\Sigma_k| + \log\pi_k$$
- Reading: (−½ Mahalanobis²) + (volume penalty) + (log-prior).
- **Don't forget** $-\tfrac12\log|\Sigma_k|$ — it survives QDA, dies in LDA.

### 6. Confusion matrix, sensitivity, specificity (write the formula even w/o numbers)
| | $\hat y=0$ | $\hat y=1$ |
|---|---|---|
| $y=0$ | TN | FP |
| $y=1$ | FN | TP |

- $\text{sens} = \text{TPR} = \text{TP}/(\text{TP}+\text{FN}) = \text{TP}/\text{P}$
- $\text{spec} = \text{TNR} = \text{TN}/(\text{TN}+\text{FP}) = \text{TN}/\text{N}$
- $\text{FPR} = 1-\text{spec} = \text{FP}/\text{N}$
- $\text{acc} = (\text{TP}+\text{TN})/n$;  $\text{err} = 1-\text{acc}$.
- Mnemonic: **S**ensitivity **S**niffs out positives (TP num); **S**pecificity **S**pares negatives (TN num).
- Threshold ↓ (0.5→0.2) → more positive preds → sens ↑, spec ↓.
- Imbalance: always-0 classifier has high acc, sens=0, spec=1.

### 7. ROC / AUC
- Axes: **y = TPR (sens)**, **x = FPR (1−spec)**. Sweep threshold $t\in[0,1]$.
- Reference points: $t=1$→(0,0); $t=0$→(1,1); ideal→(0,1); diagonal=chance.
- AUC interpretation: $\Pr(\hat p(X^+) > \hat p(X^-))$ — prob random positive ranks above random negative.
- AUC<0.5 → invert classifier; AUC invariant to monotone transforms of $\hat p$; independent of prevalence.
- Scale: 0.5 useless, 0.7 OK, 0.8 good, ≥0.9 very good.
- **LDA ≈ logistic ROC** (same linear log-odds form, different estimation).

### 8. LDA vs QDA vs Logistic vs KNN (comparison)
| | Boundary | Assumption | Params (cov) | Use when |
|---|---|---|---|---|
| Logistic | linear | none on $X$ | $p+1$ | binary, interpretable; doctors |
| LDA | linear | $X|Y=k$ Gaussian, **pooled** $\Sigma$ | $p(p+1)/2$ | Gaussian-ish, well-separated, small $n$, multi-class |
| QDA | quadratic | Gaussian, $\Sigma_k$ per class | $K\cdot p(p+1)/2$ | large $n$, classes have ≠ covariance |
| Naive Bayes | (quadratic, diag) | Gaussian, **diagonal** $\Sigma_k$ | $2pK$ | large $p$, small $n$ |
| KNN | nonparam | none | — | low $p$, large $n$; dies in high-$d$ (curse) |

- **Symmetry trap**: $p\times p$ cov has $p(p+1)/2$ free params, NOT $p^2$.
- Bias-variance: LDA simpler/biased; QDA flexible/variance.

## NICE

### A. Diagnostic vs sampling/generative paradigm
- Diagnostic: model $\Pr(Y|X)$ directly — logistic, KNN.
- Sampling/generative: model $f_k(x), \pi_k$, flip via Bayes: $\Pr(Y=k|x) \propto \pi_k f_k(x)$ — LDA, QDA, NB.

### B. Multivariate Gaussian discriminant derivation skeleton
$\log\pi_k f_k(x) = \log\pi_k - \tfrac{p}{2}\log(2\pi) - \tfrac12\log|\Sigma_k| - \tfrac12(x-\mu_k)^\top\Sigma_k^{-1}(x-\mu_k)$. Drop $k$-free → $\delta_k$. In LDA: $|\Sigma|$ and $x^\top\Sigma^{-1}x$ both $k$-free → drop both → linear. In QDA: both depend on $k$ → keep both.

### C. Parameter-count numerical anchor
$p=100, K=5$: LDA 5,050 cov params; QDA 25,250; Gaussian NB 500.

### D. LDA as dim reduction
$K$ classes → $K-1$ independent discriminant scores. Robust in high-$p$ where KNN dies.

### E. Bayes classifier vs naive Bayes
Bayes classifier = abstract optimal rule (uses true posterior). Naive Bayes = specific generative model with conditional-independence assumption. Different things — name trap.

### F. Curse of dimensionality (KNN)
High-$p$ → all pairwise distances collapse → "nearest" loses meaning → kills KNN. LDA/QDA/NB more robust.
