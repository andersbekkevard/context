# Module 11 — Neural networks — cheat-sheet candidates

## MUST

**Param count (1 hidden layer p→M→C):** `params = (p+1)M + (M+1)C`. Bias on *receiving* layer. Multilayer: sum `(prev+1)·this` over all layers. **Canonical wrong answer = forgetting biases.** Dropout does NOT reduce param count.
- Procedure: draw network, count edges (weights) + count receiving nodes (biases).
- Worked: p=3,M=4,C=1 → 4·4+1·5=**21** (2025 Q3b). p=128,M₁=32,M₂=64,C=5 → 129·32+33·64+65·5=**6565** (2023 Q5e).

**Why nonlinearity:** linear hidden activation → whole net collapses to linear regression. Nonlinearity = expressiveness (UAT requires "squashing").

**Activation table:**
| | g(z) | g'(z) | Use |
|---|---|---|---|
| Linear | z | 1 | collapses → linreg (degenerate) |
| Sigmoid | 1/(1+e⁻ᶻ) | σ(1−σ) | historical; saturates → bad gradients |
| ReLU | max(0,z) | 𝟙[z>0] | modern default |
| GELU | z·Φ(z) | smooth | smoothed ReLU |
| Softmax (output) | eᶻᶜ/Σeᶻᵏ | — | multi-class output |

**Output↔loss pairing (memorize):**
| Task | Output act | Loss |
|---|---|---|
| Regression | linear | MSE Σ(yᵢ−ŷᵢ)² |
| Binary | sigmoid | BCE −Σ[y log p̂ + (1−y) log(1−p̂)] |
| Multi-class | softmax | CCE −Σᵢ Σ_c yᵢc log p̂ᵢc |

**Sigmoid:** σ(z)=1/(1+e⁻ᶻ). **Softmax:** eᶻᶜ/Σⱼeᶻʲ.

**SGD update:** θ ← θ − λ·∇_θL. Mini-batch: ∇̂L = (1/m)Σ_{i∈B}∇Lᵢ. Unbiased.

**Hyperparameter direction-of-effect:**
- η (learning rate): ≤0.1 typical. Too large → bouncing (η=2 = "horrible"). Too small → glacial.
- Batch size: powers of 2 (32/128/256/512) — hardware only. **Larger batch → less noise → less implicit L2.**
- Dropout: 0.2–0.5; 20% common, **NEVER 50%**.

**REGULARIZATION MANDATORY** (iron rule: "never train without"). Menu: L1, L2 weight decay, **mini-batch SGD (implicit L2)**, dropout, early stopping, data augmentation, label smoothing, transfer learning.
- L2: L + λ‖w‖²; L1: L + α‖w‖₁ (sparsity). Biases excluded.
- Reduces *generalization* error; may HURT training error.

**Implicit L2 of mini-batch SGD (headline):** in over-parameterized regime with ∞ interpolators, SGD converges to **minimum-L²-norm interpolator**. "Proven." Bridge to double descent.

**Backprop = chain rule, reusing forward-pass intermediates.** Forward pass stores v, z, f; backward propagates δ output→input. Only works on feedforward (acyclic).
- Seed: δ^out = −(y−f) for MSE; δ^out_c = f_c − y_c for softmax+CCE.
- Hidden: δ^hid = δ^out · β_k · g'(v).
- General: δ^(ℓ) = (W^(ℓ+1)ᵀ δ^(ℓ+1)) ⊙ g'(v^(ℓ)).

**Universal approximation:** FNN with (i) linear output, (ii) ≥1 hidden layer of squashing (nonlinear) activation, (iii) enough width — approximates any Borel-measurable f to ε. **Existence, not construction. Proof OUT.**

**Training loop (pseudocode):**
1. init θ
2. for each minibatch B: forward (store v,z,f); compute L; backprop (δ→gradients); θ ← θ − λ∇̂L
3. repeat

## NICE

**Dropout mechanic:** zero each unit indep with prob p_drop; scale survivors by 1/(1−p_drop). Test time: no dropout. Mechanism = ensembling inside network (parallel to bagging).

**Early stopping:** train/val split; train err ↓ monotonic, val err U-shape; return params at val-min epoch. "Most common form of regularization."

**Data augmentation:** label-preserving perturbations (rotate/flip/shift/noise). Caveat: flipping "6" vertically → "9" (wrong). Natural for CNNs.

**Label smoothing:** ỹ_c = 1−ε for true class, ε/(C−1) else. ε≈0.1.

**Transfer learning:** freeze early layers of pretrained model, replace + retrain output layer on small task data.

**FNN forward formula:** ŷ_c = f(β₀c + Σ_m β_mc · g(α₀m + Σ_j α_jm x_j)).

**FNN vs GAM:** GAM = Σ_j f_j(x_j) (separable, interpretable). FNN = Σ_m β_m g(α_mᵀx) (mixes features → captures interactions).

**FNN(linear hidden + sigmoid output) = logistic regression.**

**Double descent (NN connection):** past interpolation threshold (p≫n), test err comes back down. Rewrite: min Σθ² s.t. y_i = f_θ(x_i). Implicit L2 of SGD → picks this min-norm interpolator. Post-interp solution = spikes at data points + mean baseline between.

**CNN one-liner:** feedforward + shared local **filters** + **max-pool**. Filters *learned* (not designed). Translation equivariance via weight sharing. Pattern: conv→pool→conv→pool→flatten→dense→softmax. Backprop drops in unchanged (still acyclic).

**RNN one-liner:** sequential; hidden state A_t = σ(b + W X_t + U A_{t−1}); O_t = β₀ + βᵀA_t. **Weight sharing across timesteps** (W,U,β same every t). Training = variant of backprop unrolled through time (BPTT, details OUT).

**Standardization mandatory** before NN fit (Boston exercise mean/sd).

**Forward-pass ReLU example (2025 Q3b.ii style):** weights 0.5,0,1; inputs 1,−1,−1; bias −1 → preact = −1.5 → ReLU(−1.5) = 0.

**Notation drift:** prof's λ = ISLP's ρ (learning rate); prof's M = ISLP's K (hidden width).
