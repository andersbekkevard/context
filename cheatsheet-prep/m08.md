# Module 08 — Trees — cheat-sheet candidates

## MUST

**Cost-complexity pruning (regression):**
$$C_\alpha(T) = \sum_{m=1}^{|T|}\sum_{i\in R_m}(y_i-\hat y_{R_m})^2 + \alpha|T|$$
- $|T|$ = #terminal nodes ("zeroth norm"). $\alpha=0\to T_0$; $\alpha\to\infty\to$ root.
- **Build out fully, prune backward** (weakest-link). Never early-stop: "seemingly worthless split followed by good one."
- $\alpha$ chosen by K-fold CV. Plot CV err vs **tree size** (not $\alpha$, step function).

**Classification split criteria (region $R_j$, $\hat p_{jk}=n_{jk}/N_j$):**
- Gini: $G=\sum_k \hat p_{jk}(1-\hat p_{jk})$
- Cross-entropy: $D=-\sum_k \hat p_{jk}\log\hat p_{jk}$
- Misclass: $E=1-\max_k\hat p_{jk}$
- **Asymmetry (prof-flagged):** train splits on Gini/entropy, **prune on misclassification**. Misclass insensitive to purity gains.

**Bagging variance under correlation $\rho$:**
$$\boxed{\;\mathrm{Var}\!\Big(\tfrac{1}{B}\sum X_i\Big)=\rho\sigma^2+\tfrac{1-\rho}{B}\sigma^2\;}$$
- $\rho=0\to\sigma^2/B$; $\rho=1\to\sigma^2$.
- **Floor at $\rho\sigma^2$**, doesn't shrink with $B$. RF lowers $\rho$.

**RF mtry defaults:** $m=\sqrt p$ (classification), $m=p/3$ (regression). Bagging = $m=p$. Fresh subset **per split**, not per tree.

**OOB:** $P(\text{obs }i\text{ OOB})=(1-1/n)^n\to 1/e\approx 0.368$. ~37% OOB, ~63% in-bag. Each obs OOB for $\approx B/3$ trees. No test set needed.

**Hyperparameter rule:** $B$ for bagging/RF is **NOT tuned** — "just has to be enough." Tune $m$ only. RF trees grown unpruned.

**Regression tree split criterion:** $\min_{j,s}[\sum_{R_1}(y_i-\hat y_{R_1})^2+\sum_{R_2}(y_i-\hat y_{R_2})^2]$. **Sum**, not mean. Predict region mean. Greedy, NP-hard otherwise.

## NICE

**Variable importance (two flavors):**
- Impurity: total decrease in Gini/RSS due to splits on $X_j$, avg over trees. Biased toward high-cardinality / continuous predictors.
- Permutation (OOB): shuffle $X_j$ on OOB, measure perf drop. **Prof prefers** ("makes more sense"). MeanDecreaseAccuracy / %IncMSE.

**Impurity-sensitivity example** ((400,400) parent):
- Split A: (100,300)+(300,100). Misclass=0.25, Gini=0.375.
- Split B: (200,400)+(200,0). Misclass=0.25, **Gini=1/3** (pure right node).
- Misclass blind; Gini prefers B.

**Useless-looking-split example** (70A,30B parent):
- Left (40A,5B), Right (30A,25B). Both predict A.
- Weighted misclass: 0.30 (= parent). Weighted Gini: 0.361 < 0.42. Gini sees the purity gain.

**Boston worked numbers:** single tree 35 → bagging ($m=13$) 23.67 → RF ($m=4$) 18.9.

**Deviance ↔ cross-entropy:** $\text{deviance}_j = -2\sum_k n_{jk}\log\hat p_{jk} = 2N_j\cdot D_j$. `split="deviance"` ≡ entropy.

**Categorical $q$ levels:** $2^{q-1}-1$ binary partitions. Binary-outcome trick: order levels by $\hat p_1$, treat as ordinal ($q-1$ cuts).

**Bagging can also reduce bias** (T/F trap: "bagging only reduces variance" → False).

**Weakest-link pruning:** at each step, collapse internal node whose removal increases loss the **least**. Generates nested sequence $T_0\supset T_1\supset\cdots\supset T_{\text{root}}$.

**Brain-injury counter-example:** bagging didn't improve over single tree (0.14→0.15). RF beat both. Real example of variance floor.
