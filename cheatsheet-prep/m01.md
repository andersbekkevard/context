# Module 01 — Introduction — cheat-sheet candidates

Module 01 is the framing module. No math, no derivations, no exercises. ISLP ch.1 is itself motivational, so most "delta" lives in vocabulary tags for the Q1 fill-in-the-blank. Keep this section tiny.

## MUST (would lose meaningful points without this)

- **Supervised data-generating model.** $Y = f(X) + \varepsilon$, $X=(X_1,\ldots,X_p)$, $\mathbb{E}[\varepsilon]=0$, $\varepsilon \perp X$. Course = "tools to estimate $f$." Not in ISLP §1 (it's in §2.1) — worth one line on the sheet as the anchor for every other module.

- **Reducible vs irreducible error (pointwise).** $\mathbb{E}[(Y-\hat Y)^2 \mid X=x] = (f(x)-\hat f(x))^2 + \mathrm{Var}(\varepsilon)$. The noise floor; no method beats $\mathrm{Var}(\varepsilon)$. Cross term vanishes via $\mathbb{E}[\varepsilon]=0$ and $\varepsilon\perp X$. (Module-02 atom but introduced here; if not on the sheet under m02, put it here.)

- **Q1 tag-a-scenario decoder.** Memorize the trigger words — these are the prof's exam-flagged Q1 pattern:
  - "do not care about the actual model parameters" → **prediction**
  - "understand which variables matter / sign / size of effect" → **inference**
  - "no response variable / find groups / patterns fall out" → **unsupervised**
  - "predict / classify / estimate Y" → **supervised**
  - "continuous Y" → regression; "categorical Y" → classification.

- **Prediction vs inference design-choice table.** Same model, two uses:
  - Prediction: care about test MSE/AUC, black box OK, ignore $\hat\beta$/p-values, NNs/boosting fine, want high R².
  - Inference: care about $\hat\beta$, SEs, p-values, CIs; favor linear/GAM/single tree; **low R² is OK** (Framingham).

- **LLM trap.** "An LLM is unsupervised" → **False.** Next-word prediction is fully supervised (target constructed from data itself). Same for autoencoders (input=target), masked tokens, click-prediction. Prof's distinctive point.

- **Unsupervised = "dangerous statistics."** No $y$ → no objective measure → p-values from cluster-then-test on same data are invalid (ignores the search). Honest pattern: unsupervised exploration → supervised validation on held-out data. Likely T/F: "unsupervised methods give well-calibrated p-values" → **F**.

- **Inference ≠ causality.** Prof verbatim: "ideally causal, more often correlational." Don't overclaim cause from a coefficient. T/F trap.

## NICE (include if there's space)

- **Four-cell matrix.** Supervised×{Prediction,Inference} = Forecasting / Econometrics-Framingham. Unsupervised×{Prediction,Inference} = doesn't really exist / Exploratory PCA-clustering. Useful for tag-a-scenario.

- **Three umbrella problem types.** Regression (continuous Y, M3,6,7,8) / Classification (categorical Y, M4) / Unsupervised (no Y, M10).

- **Statistical learning vs neighbors (one-liners).**
  - vs classical stats: data first, not model first; misspecification is the default.
  - vs ML: same algorithms, statistician's angle (uncertainty, bias-variance, theory under misspecification).
  - vs data science: stat learning owns steps 4–6 (model / fit / communicate). Steps 1–3 (hypothesis / scrape / structure) are out of scope.

- **Variance-stabilizing transform (Framingham).** Right-skewed response → apply $y \mapsto -1/\sqrt{y}$ to bell-shape it. Principle (transform response to stabilize variance) > exact form. Family: log, $\sqrt{\cdot}$, Box–Cox.

- **Vocabulary trap.** Avoid "independent variables" — predictors are rarely independent. Use **predictors / regressors / covariates / features**.

- **R² interpretation by goal.** Low R² is fine if the goal is inference (Framingham "blob"); low R² is bad if the goal is prediction. Reading R² without checking the goal is the trap.
