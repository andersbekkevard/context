# Module 05 — Resampling — cheat-sheet candidates

## MUST

**LOOCV OLS hat-matrix shortcut** (not in ISLP in usable form — eq 5.2 is there but the leverage interpretation is prof-specific; worth boxing):
$$\text{CV}_{(n)} = \tfrac{1}{n}\sum_i \left(\tfrac{y_i - \hat y_i}{1 - h_{ii}}\right)^2$$
$\hat y_i$ = full-data fit; $h_{ii}$ = $i$-th diag of $H = X(X^\top X)^{-1}X^\top$. **One fit only.** OLS-only (and linear-projection extensions). For trees/KNN/GAM/NN: $n$ refits.

**One-SE rule** (NOT in ISLP ch.5 — §6.1.3 only, brief; prof's preferred selection criterion):
1. $\hat\theta = \arg\min \text{CV}(\theta)$
2. $\theta^* = \min\{\theta \text{ simpler} : \text{CV}(\theta) \le \text{CV}(\hat\theta) + \widehat{\text{SE}}(\text{CV}(\hat\theta))\}$
"Simpler" = lower poly deg / larger $K$ in KNN / larger $\lambda$ / fewer nodes / fewer predictors.
$\widehat{\text{SE}}(\text{CV}_{(k)}) = \sqrt{\tfrac{1}{k-1}\sum_j (\text{MSE}_j - \overline{\text{MSE}})^2}$ (sample SD of per-fold MSEs).
**Footnote**: SE "not quite valid" — same folds used for selection AND SE estimate.

**Wrong-way vs right-way CV** (NOT in ISLP ch.5; ESL §7.10; prof exam-bait):
Rule: **anything using $y$ (correlation filter, variance filter, supervised PCA) lives INSIDE the fold.**
Setup $n=50, p=5000$ noise + random $y$ → wrong way: pre-filter top-25 by corr(x,y) on full data, then CV → ~0% misclass (LIE; truth = 50%).
Right way: redo filter inside each fold's training data → ~50% misclass.

**Bias–variance directions (CV variants)** — easy to flip:
| Method | Bias | Variance | Compute |
|---|---|---|---|
| Validation set (~50/50) | high (upward) | high | 1 fit |
| LOOCV ($k=n$) | **low** | **high** (correlated folds) | $n$ refits (or shortcut) |
| $k$-fold, $k=5,10$ | medium | **low** | $k$ fits |
Why LOOCV high-var: training sets share $n-2$ of $n-1$ obs → fold errors highly correlated → cross-cov dominates $\text{Var}(\sum a_i X_i)$. $k$-fold: two trainsets share only $(k-2)/k$ (60% at $k=5$).

**Bootstrap procedure (compressed)**:
For $b=1..B$ ($B=1000$–$10000$): draw $n$ rows w/ replacement → fit → store $\hat\theta^*_b$.
$\widehat{\text{SE}}_{\text{boot}} = \sqrt{\tfrac{1}{B-1}\sum_b(\hat\theta^*_b - \bar\theta^*)^2}$
95% CI: **percentile** (2.5%/97.5% quantiles of $\{\hat\theta^*_b\}$) OR normal $\bar\theta^* \pm 1.96\cdot\text{SE}_{\text{boot}}$.
**Always with replacement, always size $n$** (w/o replacement at $n$ = permutation = useless).
Central idea: "your best model for the world is the data itself."

**OOB / $1-1/e$ derivation** (hand-calc target):
$P(\text{obs }i\text{ not drawn, single}) = 1 - 1/n$
$P(\text{not drawn in any of }n) = (1-1/n)^n \to 1/e \approx 0.368$
→ ~37% OOB, ~63% in-bag per bootstrap sample.

**Wrong-way CV / nested-CV trap** — quick recipe:
- Inner folds → SELECTION; Outer folds → ASSESSMENT.
- Once CV picks the model, that same CV-error **cannot** honestly assess it (you optimized against it).

## NICE

**$k$-fold CV pseudocode** (CE1 4a pattern):
```
for K in K_set:
  for j=1..k: fit on data\C_j; predict on C_j; MSE_j
  CV(K) = (1/k)Σ MSE_j
K* = argmin CV(K); refit on all training data; report on test set
```

**Weighted $k$-fold formula** (slide form, general):
$\text{CV}_{(k)} = \tfrac{1}{n}\sum_j n_j \text{MSE}_j$, equals $\tfrac{1}{k}\sum_j \text{MSE}_j$ when folds equal.
Classification: swap $\text{MSE}_j \to \text{Err}_j = \tfrac{1}{n_j}\sum_{i\in C_j}\mathbb{1}(y_i \ne \hat y_i)$.

**Independence trap** (prof's longest tangent):
Random folds break under spatial/temporal/clustered correlation. LOOCV extra-bad (neighbor predicts held-out → CV says "most complex model wins"). Fix: chunk by dependency dimension, fold whole blocks.

**Train / validation / test = three jobs**: fit / select / assess. CV replaces **validation**, not test. Pipeline: split off test once → CV on rest → refit on rest with chosen $\theta$ → score on test.

**Bagging variance formula** (motivates RF; prof previews here):
$\text{Var}(\bar f_B) = \rho\sigma^2 + \tfrac{1-\rho}{B}\sigma^2$
$\rho\sigma^2$ floor doesn't shrink with $B$ → RF decorrelates by random subset of predictors.

**Classification-CV training-error rises with flexibility**: logistic regression minimizes likelihood, not 0/1 → more params doesn't guarantee lower misclass. Whenever optimized loss ≠ reported metric, "more flexibility" loses guarantee.

**Bootstrap regression-coeff SE vs closed form**: $\widehat{\text{Cov}}(\hat\beta) = \hat\sigma^2(X^\top X)^{-1}$ agrees w/ bootstrap when IID-Gaussian residuals hold; **bootstrap closer to truth when they don't.**

**Bootstrap for derived quantity** (CE1 4d): same recipe, statistic = $\hat p(x_0)$ from logistic refit; percentile CI of $\{\hat p^*_b(x_0)\}$.
