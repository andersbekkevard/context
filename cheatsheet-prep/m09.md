# Module 09 — Boosting — cheat-sheet candidates

## MUST

**Boosting in one line** (the prof's exam-flagged framing):
Sequential weak learners + a differentiable loss + additive combination (with shrinkage).
$$f_M(x) = \sum_{m=1}^M \nu \cdot T(x; \Theta_m), \qquad \nu \in (0,1]$$
Each tree fits the **negative gradient** of the loss w.r.t. current ensemble — for squared error this = residuals. Boosting attacks **bias** (bagging/RF attack variance).

**Hyperparameter direction-of-effect table** (prof flagged: 2025 Q6c / Exercise 9.3 — *"how do you determine good values?"* → CV / early stopping):
| Knob | ↑ effect | Typical | Bias/Var |
|---|---|---|---|
| $\nu$ (shrinkage / learning rate) | ↑ → fewer trees needed; risk overshoot | $\le 0.1$ (0.01–0.1) | ↑ν = ↑var, ↓bias per step |
| $M$ (# trees, = ISLP $B$) | ↑ → fits residual noise; **real tuning param** (unlike RF) | tune by CV / early stop | ↑M = ↓bias then ↑var (U) |
| $d$ / $J$ (depth / leaves; $J = d+1$) | ↑ → captures higher-order interactions | $4 \le J \le 8$ | ↑depth = per-step overfit, ↑var |
| min-obs-per-node | ↑ → smoother leaves | less critical for big $N$ | minor |

**$M$–$\nu$ coupling**: smaller $\nu$ ⇒ larger $M$ needed. **Recipe**: fix $\nu \approx 0.1$, tune $M$ by CV minimum / early stopping. Depth set by interaction-order rule below.

**Interaction-order rule**: tree with $J$ leaves → $J{-}1$ splits → models up to $(J{-}1)$-way interactions. $J=2$ (stumps) = purely additive; $J=6$ = up to 5-way.

**Gradient boosting one-line algorithm** (Algorithm 10.3 — *not* in ISLP, only Alg 8.2 = squared-error special case):
Init $f_0 = \arg\min_\gamma \sum_i L(y_i,\gamma)$. For $m=1..M$:
1. $r_{im} = -\big[\partial L(y_i,f(x_i))/\partial f(x_i)\big]_{f=f_{m-1}}$  (neg-gradient pseudo-residuals)
2. Fit regression tree to $\{r_{im}\}$ by least squares → regions $R_{jm}$
3. $\gamma_{jm} = \arg\min_\gamma \sum_{x_i \in R_{jm}} L(y_i, f_{m-1}(x_i) + \gamma)$  (leaf values from *original* loss)
4. $f_m(x) = f_{m-1}(x) + \nu \sum_j \gamma_{jm}\,\mathbb{1}(x \in R_{jm})$

**Squared-error sanity check**: $L = \tfrac12(y-f)^2 \Rightarrow -\partial L/\partial f = y - f = r$. Residual *is* the negative gradient. ISLP Alg 8.2 = Alg 10.3 with squared error.

**AdaBoost.M1** (NOT in ISLP — entire algorithm is delta):
Setting: $y_i \in \{-1,+1\}$, weak $G_m \in \{-1,+1\}$. Init $w_i = 1/N$. For $m=1..M$:
1. Fit $G_m$ with weights $w_i$
2. $\mathrm{err}_m = \frac{\sum_i w_i \mathbb{1}[y_i \ne G_m(x_i)]}{\sum_i w_i}$
3. $\alpha_m = \log\frac{1-\mathrm{err}_m}{\mathrm{err}_m}$
4. $w_i \leftarrow w_i \cdot \exp(\alpha_m \cdot \mathbb{1}[y_i \ne G_m(x_i)])$

Output: $G(x) = \operatorname{sign}\!\big(\sum_m \alpha_m G_m(x)\big)$.

**Structural facts**: misclassified → weight $\times e^{\alpha_m}$ (up); correct → $\times 1$ (unchanged). $\mathrm{err}_m < 1/2 \Rightarrow \alpha_m > 0$; $\mathrm{err}_m > 1/2 \Rightarrow \alpha_m < 0$ (vote auto-flipped); $\mathrm{err}_m = 1/2 \Rightarrow \alpha_m = 0$. AdaBoost = forward-stagewise additive modeling under exponential loss $L(y,f) = \exp(-yf)$.

**Bagging vs RF vs Boosting comparison**:
| | Bagging | Random Forest | Boosting |
|---|---|---|---|
| Trees | parallel, indep | parallel, indep, decorrelated ($m=\sqrt{p}$) | **sequential**, residual-driven |
| Each tree | deep (high var, low bias) | deep (high var, low bias) | **shallow** (low var, high bias) |
| Attacks | variance | variance | **bias** |
| #trees $B/M$ | "enough" — no overfit | "enough" — no overfit | **real tuning param** — overfits if too large |
| OOB available | yes | yes | **no** (uses full data per tree) |

**Loss menu** (negative gradients — fair game):
- Squared $\tfrac12(y-f)^2$ → $y-f$ (residual). Outlier-sensitive.
- Absolute $|y-f|$ → $\operatorname{sign}(y-f)$. Robust; V-shape kink at 0.
- Huber: quadratic near 0, linear in tails. Engineered middle path.
- Exponential $\exp(-yf)$, $y \in \{\pm1\}$ → AdaBoost's implicit loss.
- Binomial deviance ($y\in\{0,1\}$, $p = e^f/(1+e^f)$) → $y - p$ ("indicator minus prob"). = logistic NLL.
- Multinomial deviance ($K$ classes, softmax) → $\mathbb{1}(y_i=k) - p_k(x_i)$. **Fits $K$ trees per round** (one per class) — exam trap.

## NICE

**Stochastic gradient boosting** (Friedman 2002, NOT in ISLP):
Subsample without replacement (≠ bootstrap):
- rows before each tree (`bag.fraction`, typ 0.5)
- columns before each tree
- columns before each split (RF-style)
Adds variance reduction on top of $\nu$ + early stopping. **Three regularizers**: small $\nu$ + early stop on $M$ + stochastic subsampling.

**XGBoost extras** (NOT in ISLP — concept only; the prof explicitly OUT internals):
- 2nd-order Taylor: $L \approx L_0 + g_i t + \tfrac12 h_i t^2$ → Newton step, not just gradient
- L2 leaf penalty: $\Omega(T) = \gamma|T| + \tfrac12\lambda\|w\|_2^2$ (also L1 form)
- Closed-form leaf weight: $w_j^* = -\frac{\sum_{i\in R_j} g_i}{\sum_{i\in R_j} h_i + \lambda}$
- $\gamma$ = per-leaf pruning threshold (split rejected if gain $< \gamma$)
- Dropout (DART): randomly drop trees when computing residuals
- Parallelization + approximate (quantile-binned) split search

**FSAM → AdaBoost equivalence** (the mini-derivation prof did on board):
With $w_i^{(m)} = \exp(-y_i f_{m-1}(x_i))$, FSAM objective splits as $e^{-\beta}\sum_{\text{correct}} w_i + e^\beta \sum_{\text{wrong}} w_i$. Minimize over $\beta$:
$$\beta_m = \tfrac12 \log\frac{1-\mathrm{err}_m}{\mathrm{err}_m}$$
(AdaBoost's $\alpha_m = 2\beta_m$; factor of 2 absorbed at sign rule.)

**Partial dependence plot (PDP)** — empirical estimator (exam-writable):
$$\bar f_j(x_j) = \frac{1}{N}\sum_{i=1}^N f(x_j, x_{i,-j})$$
For grid $x_j^{(k)}$: replace $j$-th coord with $x_j^{(k)}$, predict, average. Reading: *marginal effect after accounting for other vars*, **not causal**. Fragile under correlated predictors (synthetic implausible rows).

**Variable importance for boosting**: sum impurity decrease (RSS / Gini) across splits on $X_j$ over **all $M$ trees**. ISLP §8.2.1 covers it for bagging only; boosting transposes the same construction. No OOB-permutation flavor for boosting (no bootstrap).

**Why weak learners** (prof flagged as discussion-Q): small step along negative gradient; deep tree overfits per step, breaks additive-correction logic; bias gets aggregated without inviting variance; $\nu$ = step size, weak learners enforce small steps.

**Notation drift** (open-book trap):
- ISLP $B$ ↔ prof $M$ (#trees)
- ISLP $\lambda$ ↔ prof $\nu$ or $\eta$ (shrinkage) — **collides with ridge/lasso $\lambda$ AND XGBoost's L2 $\lambda$**
- ISLP $d$ (splits) ↔ prof $J$ (leaves), $J = d+1$
