# Module 10 — Unsupervised — cheat-sheet candidates

## MUST

**Hierarchical clustering by-hand recipe (EXAM TARGET, −1/mistake)**
1. Find smallest off-diag D_ij → fuse {i,j} at h = D_ij
2. Recompute D({i,j},k) by linkage rule (complete=max, single=min, average=mean)
3. Repeat on shrunken matrix until 1 cluster
4. Dendrogram: y = fusion height; x-order arbitrary
5. Cut at h to get K clusters
Mistakes propagate → always rewrite the matrix.

**Linkage direction-of-effect (memorize)**
- Complete = max → BALANCED clusters
- Single = min → CHAINING (long snaking)
- Average = mean → balanced, middle-ground, most popular
- Ward, centroid: OUT/ignore

**PCA score formula (Q3c exam target)**
z_im = Σ_j φ_jm · x_ij (plug observation into loading vector)

**PVE / cumulative PVE (Q3a,b exam target)**
- PVE_m = λ_m / Σ_k λ_k
- After standardize: Σλ_k = p, so PVE_m = λ_m / p
- 90% recipe: cumulative sum λ_m / p until ≥ 0.90 → smallest such M
- Worked: 0.54 → 0.84 → 0.94 → answer M=3

**Loadings constraint:** Σ_j φ_jm² = 1 (unit norm)

**PCA = NOT scale invariant → STANDARDIZE FIRST**
Else largest-variance variable dominates PC1 (USArrests Assault example).
z_ij = (x_ij − x̄_j) / s_j

**K-means objective**
min Σ_k Σ_{i∈C_k} ||x_i − x̄_k||² (squared Euclidean, no √)
Equivalently: (1/|C_k|) Σ_{i,i'∈C_k} ||x_i − x_i'||² (Eq 12.17/18 link)

**K-means algorithm**
1. Random init assignments
2. (a) Centroids = cluster means; (b) Reassign to nearest centroid
3. Iterate until no changes → LOCAL min only

**Random init pitfall (prof's headline)**
"Can really screw you" → run nstart ≥ 20, keep lowest WSS.

**Scree plot reading**
- Scree (PVE per m): decreasing; chop at ELBOW
- Cumulative: increasing toward 1; chop at threshold 90/95/99%
- Unsupervised: elbow/threshold; Supervised (PCR): use CV instead

**Dendrogram reading (T/F trap)**
- y-axis (fusion height) = info; x-axis = ARBITRARY (2^(n-1) orderings)
- "9 and 2 close horizontally → similar" = FALSE

**Hierarchical vs K-means**
- Hier: nested partitions, dendrogram, no K needed upfront
- K-means: flat partition, must pick K, NO nesting across K

## NICE

**Variance of PC m = λ_m**
Var(Z_m) = φ_m^T Σ φ_m = λ_m (the fact; don't derive)

**PCA optimization (quadratic form)**
max_{||φ||=1} φ^T Σ φ → top eigenvector of Σ

**Correlation distance**
d_corr = 1 − ρ(x_i, x_i') ∈ [0,2]
Use when SHAPES matter (preferences), not magnitudes (volume).
Shopper example: Euclidean groups infrequent shoppers; correlation groups similar tastes.

**Why squared Euclidean in K-means**
Monotone in plain Euclidean → same partition; squared makes centroid = arg min in closed form (mean). Plain Eucl → geometric median (hard).

**K-means monotonicity proof (Exercise 10.2)**
Use Eq 12.18 to rewrite as Σ ||x_i − x̄_k||². Centroid step: mean minimizes Σ ||x_i − c||². Assign step: each point picks min. Both weakly decrease nonneg → converges to local min.

**K^n partitions, why iterate**
n=1000, K=10 → 10^1000 partitions. Must use greedy algo.

**Choosing K (k-means)**
Elbow on WSS, domain knowledge, downstream interpretability. NO CV (no Y).
OUT: gap statistic, silhouette, K-means++.

**Centroid linkage caveat**
Can produce INVERSIONS (fusion below child). Avoid.

**Curse of dimensionality + Euclidean**
High-p → all pairwise dists bunch up. Dim-reduce first or use Manhattan/correlation.

**Trivial K=n**
Every point own cluster → objective = 0, no learning.

**Loadings unique up to sign**
Sign flip between packages = not a bug.

**PCA decorrelates by construction**
Scores Z_m are uncorrelated (φ's orthogonal). Fix for collinearity.
