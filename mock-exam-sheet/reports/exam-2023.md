# Exam 2023 — Cheat-sheet candidates

## Question summary

- **P1 (fill-in-blank)**: Module-2 framing vocabulary — supervised/unsupervised, parametric/non-parametric, prediction/inference, bias-variance trade-off, regularization, irreducible vs reducible error.
- **P2 (Trees + Bayes boundary)**:
  - (a) Sketch a regression tree from a 2D partition with mean-of-y in each region.
  - (b) Bayes decision boundary for a 2-class problem where class 0 is a **mixture of two Gaussians** and class 1 is a single Gaussian (shared Σ). Asked to write the equation, explain unknowns, and decide whether the boundary is linear/quadratic — it is **neither** (mixture density inside an exp breaks log-linearization).
- **P3 (regression, birthwt)**: OLS on all predictors except `low`; interpret black-vs-white race coefficient; F-test for `race` (anova); R² vs adjusted R²; expand with `smoke*age` interaction and interpret "smoking effect changes with age"; combined effect of `age + age:smoke` × 10; Lasso vs OLS shrinkage pattern (some hit zero; ridge would shrink but never zero); test MSE comparison across OLS / OLS+interaction / Lasso; pick a more flexible method (GAM with `bs(lwt,4)` or RF with `mtry=p/3`, ntree "large enough").
- **P4 (classification, birthwt)**: Logistic on all predictors except `bwt`; predict probability for a specific covariate vector by hand via logit; **interpret smoking effect via odds-ratio = exp(β_smoke)**, not by re-running with smoke=0; error rate, sensitivity, specificity from a confusion matrix; same with RF (mtry=√p); compare methods — RF lower error but very low sensitivity, so logistic preferred for medical context.
- **P5 (single choice)**: (a) training RSS strictly decreases as Lasso budget s ↑; (b) bias strictly decreases as s ↑; (c) Bootstrap-vs-glm SE discrepancy reveals **violation of GLM distributional assumptions**, not a bootstrap problem; (d) single-vs-complete linkage on same fusion — complete linkage fuses higher (and "not enough information" also accepted); (e) NN parameter count with biases: 129·32 + 33·64 + 65·5.
- **P6 (multiple choice)**: (a) Which methods do variable selection — trees + Lasso yes, "all regularization" + CNNs no. (b) Forward/backward AIC selection — not justified for inference; introduces model-selection bias; replacing AIC with BIC doesn't fix it. (c) k-fold vs LOOCV — 5-fold has more bias, less variance than LOOCV; validation set ≠ 2-fold CV (it fits once, not twice); LOOCV expensive except linear-regression shortcut. (d) PCR is not variable selection; smoothing-spline penalty is on **second** derivative, not first; KNN high K → high bias. (e) Non-linear SVM boundary $(X_1+2)^2 + (X_2+2)^2 - 2X_2^3 = 0$ — not linear in $X_1^2,X_2^2$ (the cubic kills it), not a circle, plug in test points by hand.

## High-priority surfacing

- **Bayes boundary for class-0-as-mixture, class-1-as-Gaussian** (filter A, D) — when one class density is a *sum* of Gaussians, the log transform cannot kill the exponentials (a sum-of-exps doesn't simplify), so the boundary is **neither linear nor quadratic**. Default LDA/QDA reasoning fails — this is the case the prof's flagged "where does the quadratic come from" template does NOT cover. — Q2(a)(ii)–(iii) — TMA4268_2023_Exam.Rmd:111–142 — Equation: $f_0(x)\pi_0 = f_1(x)\pi_1$; mixture in $f_0$ ⇒ log doesn't collapse ⇒ non-linear, non-quadratic.
- **Procedural template: 2D Bayes boundary from priors + densities** (filter D) — the prof flagged this as *the* exam template for module 4. Steps: set $f_0\pi_0 = f_1\pi_1$, plug in given μ's, Σ, π's, and either solve or argue about form. See full algebra in wiki/book-deltas/m04-classif.md:186–244. — Q2(a)(ii) — TMA4268_2023_Exam.Rmd:122–142 — Template: `v = Σ⁻¹(μ_A−μ_B); c = −½μ_A'Σ⁻¹μ_A + ½μ_B'Σ⁻¹μ_B + log(π_A/π_B); boundary v'x + c = 0`.
- **Race coefficient = expected difference in y vs reference category** (filter B) — for a K-level factor with K-1 dummies, the coefficient on `race2` is the expected response **difference between race2 and the omitted (reference) race**, holding others fixed. Easy interpretation trap on dummy reference levels. — Q3(a)(ii) — TMA4268_2023_Exam.Rmd:178, 188 — Read it as: $\hat{y}_{\text{black}} - \hat{y}_{\text{white}} = \hat\beta_{\text{race2}}$ grams.
- **F-test for an entire categorical factor uses ANOVA, not individual t-stats** (filter B, C) — to test whether `race` (multi-level factor) belongs in the model, run an F-test on the joint hypothesis $\beta_{\text{race2}}=\beta_{\text{race3}}=0$ via anova(), not by inspecting individual dummy p-values. — Q3(a)(iii) — TMA4268_2023_Exam.Rmd:179, 189–193 — Decision rule: anova partial-F p<0.05 ⇒ factor is relevant overall.
- **R² vs adjusted R² gap = irrelevant predictors signal** (filter B) — when $R^2$ is noticeably larger than $R^2_{\text{adj}}$, the model contains predictors that aren't pulling weight. Conversely, similar values indicate a parsimonious fit. Adjusted R² penalizes by $(n-1)/(n-d-1)$. — Q3(a)(iv) — TMA4268_2023_Exam.Rmd:180, 195 — Read: $R^2=0.267$, $R^2_{\text{adj}}=0.216$ ⇒ "some unnecessary variables."
- **Interaction-coefficient interpretation: combined age effect when smoking** (filter B, D) — for `bwt ~ age + smoke + age:smoke`, the *total* effect of age when smoke=1 is $\beta_{\text{age}} + \beta_{\text{age:smoke}}$; expected change for a 10-year age gap among smokers = $10\cdot(\hat\beta_{\text{age}} + \hat\beta_{\text{age:smoke}})$. All-or-nothing graded in this exam. — Q3(b)(ii) — TMA4268_2023_Exam.Rmd:200–212 — Hierarchical principle: keep both main effects when you keep the interaction.
- **Lasso vs Ridge comparison pattern** (filter B, C) — the textbook-correct articulation the prof's exam key expects: "(1) Lasso *shrinks* coefficients toward zero; (2) Lasso sets *some exactly* to zero; (3) Ridge would also shrink, but (4) **none would be exactly zero**." Each clause was worth 0.5P — saying only "some are near zero in ridge" loses points. — Q3(c)(ii) — TMA4268_2023_Exam.Rmd:217, 262 — Geometric reason: L1 ball has corners on axes; L2 ball doesn't.
- **`ntree`/`B` is NOT a tuning parameter — pick "large enough"** (filter C) — explicit deduction in the exam key: "ntrees is not a tuning parameter, so the students should not optimize it." Must say "large enough that OOB error plateaus," not "I used 500 from the default." Tune `mtry` instead. — Q3(e), Q4(c)(i) — TMA4268_2023_Exam.Rmd:308, 471 — Defaults: `mtry = p/3` regression, `mtry = √p` classification.
- **Probability prediction by hand via logit inversion** (filter D) — given the fitted glm coefficients and an x-vector, compute η = β'x, then p = e^η/(1+e^η). Note the leading 1 in x for the intercept. The prof flagged this exact mechanic in wiki/book-deltas/m04-classif.md:92–114. — Q4(a)(ii) — TMA4268_2023_Exam.Rmd:369–401 — Pattern: `x.data=(1,age,lwt,race2,race3,smoke,ptl,ht,ui,ftv)`; multiply, sigmoid.
- **"Overall smoking effect" = odds ratio $e^{\hat\beta_{\text{smoke}}}$, NOT re-running with smoke=0** (filter B, C) — the prof's note: "students must NOT repeat the analysis from (a) with smoke=0." General statement independent of other variables = the multiplicative odds factor. — Q4(b)(i) — TMA4268_2023_Exam.Rmd:407, 421–425 — Phrasing: "Odds for low birth weight increase by a factor of $e^{\hat\beta_{\text{smoke}}}$ for smoking vs non-smoking women."
- **RF lower error but lower sensitivity → choose by context, not just accuracy** (filter B, C) — exam key spells it out: in medical context, missing a true positive ("risk patient") is worse than a false positive, so even though RF has lower misclassification error, **logistic regression is preferable** because its sensitivity is higher. Direction-of-effect: accuracy alone can be misleading on imbalanced classes. — Q4(c)(ii) — TMA4268_2023_Exam.Rmd:448, 484 — Decision rule: optimize the metric that matches the cost asymmetry (sens > acc when FN is costly).
- **Bootstrap-SE vs GLM-SE disagreement diagnoses GLM assumptions, NOT a bootstrap flaw** (filter B, C) — single-choice key answer is (ii): when bootstrap SE differs from glm SE, the **distributional assumptions** of the GLM (Wald approx, asymptotic normality) are suspect. The bootstrap is the more trustworthy of the two because it makes fewer assumptions (cf. wiki/concepts/bootstrap.md:91–93). — Q5(c) — TMA4268_2023_Exam.Rmd:548–570 — Trap: option (iv) "sampling without replacement" is the canonical bootstrap-trivia distractor.
- **NN parameter count must include bias nodes per layer** (filter D) — for an MLP with input p, hidden widths $h_1, h_2$, output $C$: total params = $(p+1)h_1 + (h_1+1)h_2 + (h_2+1)C$. Concrete: 128→32→64→5 gives $129\cdot32 + 33\cdot64 + 65\cdot5 = 6533$. Dropout does NOT reduce parameter count (it's a training-time mask), mini-batch size is irrelevant to counting. — Q5(e) — TMA4268_2023_Exam.Rmd:592–602 — Memorize: bias adds **+1 per layer's input dimension**.
- **Linkage trap: complete fuses higher than single linkage on the *same* fusion** (filter B) — when clusters {1,2} and {3,4,5} fuse in both single and complete, complete-linkage fusion height ≥ single-linkage fusion height because complete uses max pairwise distance vs single's min. Note: this exam credits both (ii) "complete higher" and (iv) "not enough info" — the strict guarantee is height_complete ≥ height_single, with equality possible. — Q5(d) — TMA4268_2023_Exam.Rmd:576–586 — Compact: $d_{\text{complete}}(A,B) \geq d_{\text{single}}(A,B)$ for any pair of clusters.
- **AIC/BIC stepwise: model selection bias is unavoidable; BIC doesn't fix it** (filter B, C) — exam-key truths: (i) automatic selection is **not justified for inference** (Tier-1 prof opinion: invalidates post-selection p-values); (ii) it induces **model selection bias**; (iii) p-values from the final model tend to be **too small** (anti-conservative), not too large; (iv) BIC vs AIC swap doesn't rescue the procedure. — Q6(b) — TMA4268_2023_Exam.Rmd:619–628 — Direction-of-effect trap on (iii): "too large" is wrong; selection inflates significance, not deflates.
- **5-fold CV vs LOOCV — bias-variance reversal** (filter B, C) — 5-fold has **more bias, less variance** than LOOCV in the estimated test error (LOOCV trains on near-full data so each fold's training set is nearly identical → high pairwise correlation → high variance of the average). The "validation set ≠ 2-fold CV" subtlety: 2-fold trains *twice*, validation-set trains *once*. LOOCV is generally **expensive** (only cheap for linear regression via the leverage shortcut). — Q6(c) — TMA4268_2023_Exam.Rmd:632–645 — Compact: variance(LOOCV) > variance(k=5); bias(LOOCV) < bias(k=5).
- **Smoothing-spline penalty is on g″, NOT g′** (filter B) — exam-key trap directly: penalty is $\int g''(t)^2 dt$, penalizing **curvature**. Penalty on $g'$ would penalize slope (a horizontal line minimizes it; doesn't enforce smoothness in the curvature sense). — Q6(d)(iii) — TMA4268_2023_Exam.Rmd:655, 662 — Memorize: second-derivative penalty ⇔ smoothness.
- **Non-linear SVM boundary: cubic terms break "linear in basis" claims** (filter B, D) — boundary $f = (X_1+2)^2 + (X_2+2)^2 - 2X_2^3$ is **not** linear in $\{X_1, X_2, X_1^2, X_2^2\}$ because the $X_2^3$ term doesn't expand into those basis functions; and it's **not** a circle because circles are level sets of $X_1^2 + X_2^2 + \text{linear}$, here the cubic deforms it. Procedure for class-membership questions: just plug $(x_1, x_2)$ into $f$ and check sign. — Q6(e) — TMA4268_2023_Exam.Rmd:669–686 — Compact: SVM "linear in features" requires all features explicitly listed; verify by expanding.

## Lower-priority but useful

- **PCR is NOT variable selection** (filter B) — Q6(d)(i) — TMA4268_2023_Exam.Rmd:653, 660 — PCR uses linear combinations of *all* p variables in each PC, so variables are not dropped — only directions are. Compare to Lasso, which is genuine selection.
- **SVM cost C interpretation (textbook-ambiguous)** (filter B) — Q6(d)(ii) — TMA4268_2023_Exam.Rmd:654, 661 — Notational warning: ISLP and sklearn use opposite C conventions. Small ISLP C → narrow margin (low bias / high variance); small sklearn C → strong regularization (high bias / low variance). The 2023 key marked both answers correct due to ambiguity.
- **KNN high K → high bias** (filter B) — Q6(d)(iv) — TMA4268_2023_Exam.Rmd:656, 663 — Direction: K=N → constant prediction = ultimate bias. K=1 → zero training error, max variance.
- **Mixture-of-Gaussians density form** (filter A) — Q2(a)(ii) — TMA4268_2023_Exam.Rmd:86–97 — Not in ISLP §4.4 (only single-Gaussian class densities). The mixture form $f_k(x) = \sum_m w_m \phi(x; \mu_{km}, \Sigma)$ matters whenever within-class data is multi-modal — neither LDA nor QDA captures this.
- **GAM with cubic spline on continuous variable + factors** (filter C) — Q3(e) — TMA4268_2023_Exam.Rmd:313–318 — Pattern: pre-screen variables (via Lasso), then GAM = bs(continuous, df) + main effects on factors. Explains which variables get smoothed and why.
- **Validation set approach ≠ 2-fold CV** (filter B) — Q6(c)(iii) — TMA4268_2023_Exam.Rmd:638, 645 — Validation: split, train once on one half, evaluate on other. 2-fold CV: split, train **twice** (each half is training in one fold), average the two errors. Different cost, different bias.
