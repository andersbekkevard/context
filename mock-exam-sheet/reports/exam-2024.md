# Exam 2024 — Cheat-sheet candidates

## Question summary

- **Q1 (5P) Fill-in-the-blank**: parametric vs non-parametric, prediction vs inference, lasso vs model selection bias, tree pruning = shrinkage analogue, NN regularization (weight penalization), unsupervised vs response-present.
- **Q2 (7P) Multiple choice / numeric**: which methods allow p>n (forward/backward/lasso/ridge/boosting); NN architecture parameter count (with biases); natural cubic spline df with 3 knots; regression-tree path prediction.
- **Q3 (8P) Theory**: (a) k-fold CV mechanics and k-fold vs LOOCV trade-off; (b) least-squares vs MLE and their equivalence under Gaussian errors (derivation).
- **Q4 (16P) Carseats regression**: lm with categorical + interactions, F-test of ShelveLoc factor, prediction by hand with reference-level encoding, `plot(mod)` diagnostic reading, then ridge / lasso with 1-SE λ on training, MSE comparison, coefficient pattern (sparsity).
- **Q5 (16P) OJ classification**: logistic regression on full + reduced (collinearity with PriceDiff/PriceCH/PriceMM), odds-ratio interpretation per 0.1 change, QDA confusion table + sensitivity/specificity/error, GAM with `ns()` smoothers on two predictors, then `gbm` boosting with n.trees/shrinkage/depth, model comparison.
- **Q6 (7.5P) MC/numeric**: salary lm with GPA·IQ + GPA·Gender (sign-of-interaction trap), standardization which-methods, identify objectives (OLS / lasso / k-means / regression tree), PCA biplot + scree interpretation (state.x77).

## High-priority surfacing

- **NN parameter count = M(p+1) + C(M+1) with biases** (filter A, partly D) — must count biases per receiving layer; canonical wrong answer skips biases — Q2b — exams/TMA4268_2024_Exam.Rmd:95 — for stated arch: `10*7 + 8*6 + 7 = 125`. Formula: layer-by-layer `(prev+1)·this`.
- **Natural cubic spline df with K knots = K + 1** (filter A) — natural splines impose linearity beyond boundary knots, cutting 4 df from an unconstrained cubic spline (K+4). For K=3 → df=4 — Q2c — exams/TMA4268_2024_Exam.Rmd:104 — compact: `df_NS = K + 1` (intercept implicit in model); contrast with unrestricted cubic spline df = K + 4.
- **p>n feasibility map** (filter C) — Ridge OK for p>n (penalty makes X'X+λI invertible). Forward selection OK for p>n (stops at n−1 predictors). Backward selection FAILS for p>n (can't start from full model). Lasso OK for p>n but selects ≤ n predictors. Boosted trees OK. NN does not require p>n — Q2a — exams/TMA4268_2024_Exam.Rmd:72-77.
- **k-fold CV vs LOOCV bias-variance trade-off** (filter B, D) — LOOCV: ~unbiased but **high variance** (n nearly-identical fits → correlated errors); k=5/10: slight upward bias (smaller training sets) but **lower variance** + far cheaper — Q3a — exams/TMA4268_2024_Exam.Rmd:138 — compact: `LOOCV: low bias / high var; k=5,10: balanced`.
- **OLS ≡ MLE under Gaussian errors (derivation)** (filter D) — Plug `Y_i ~ N(f_θ(X_i), σ²)` into log-lik: `−N/2·log(2π) − N/2·log(σ²) − (1/2σ²)Σ(y_i − f_θ)²`. First two terms drop, maximizing log-lik over θ ≡ minimizing RSS. Prof flagged this derivation type — Q3b — exams/TMA4268_2024_Exam.Rmd:166-174.
- **Logistic odds-ratio interpretation per Δx (not per unit)** (filter B) — A coefficient β with predictor changing by Δ multiplies the odds by `exp(β·Δ)`, NOT `exp(β)·Δ`. Q asks for Δ=0.1 → factor `exp(0.1·β)` — Q5a(ii) — exams/TMA4268_2024_Exam.Rmd:414 — compact: `OR(Δ) = exp(βΔ)`. Trap = forgetting Δ.
- **Reference-level encoding of categorical predictors** (filter B) — Predicting requires knowing which level is reference. With levels (Bad, Medium, Good) and reference=Bad: ShelveLoc=Good adds β_Good directly; moving Medium→Good adds (β_Good − β_Medium) ≈ 4.83 − 1.91 ≈ 2.93 thousand units — Q4a(iii) — exams/TMA4268_2024_Exam.Rmd:242 — compact: `Δ_M→G = β_Good − β_Medium`.
- **Interaction-term direction-of-effect (Gender × GPA)** (filter B) — Salary = 50 + 20·GPA + 0.07·IQ + 35·F + 0.01·GPA·IQ − 10·GPA·F. Female−Male gap = 35 − 10·GPA. Females earn more only when 35 > 10·GPA i.e. GPA < 3.5; for high GPA males earn more — Q6b — exams/TMA4268_2024_Exam.Rmd:587-595 — compact: gap-sign flips at GPA = 3.5.
- **Standardization-required map** (filter C) — TRUE for ridge/lasso (penalty depends on scale), PCA (variance dominated by largest-unit variable), KNN (Euclidean distance). FALSE for OLS (scale just rescales β̂s) — Q6c — exams/TMA4268_2024_Exam.Rmd:619 — compact: `OLS no; Ridge/PCA/KNN yes`.
- **Tree-as-shrinkage analogue = pruning; NN-as-shrinkage = weight penalization** (filter C) — Conceptual mapping the prof emphasizes: every method has its regularization knob — Q1 — exams/TMA4268_2024_Exam.Rmd:55.
- **Lasso vs AIC-based selection: lasso avoids "model selection bias"** (filter A) — Prof's framing (not standard ISLP language): selecting via discrete AIC and then refitting OLS produces over-confident, biased coefficient estimates; lasso shrinks-and-selects in one step — Q1 — exams/TMA4268_2024_Exam.Rmd:54 — compact: AIC stepwise + refit → "model selection bias".
- **Ridge vs Lasso coefficient pattern** (filter B, C) — Both shrink toward 0; only lasso sets some to exactly 0 (L1 corners at axes). Compare to OLS to show shrinkage direction; trade-off = sparsity/interpretability vs bias — Q4b(v) — exams/TMA4268_2024_Exam.Rmd:366 — compact: `Ridge: shrink, none zero; Lasso: shrink + select`.
- **F-statistic "last row" = global test** (filter B) — Tests H₀: β₁=…=β_p=0 (all slopes zero) vs H₁: at least one nonzero. Tiny p → reject ⇒ "at least one coefficient is nonzero". Different from per-coefficient t-tests — Q4b(ii) — exams/TMA4268_2024_Exam.Rmd:330 — compact: `global F: any slope ≠ 0?`.
- **QDA confusion-table → sens / spec / error** (filter B) — With rows=true, cols=predicted: `sens = TP/(TP+FN) = t[2,2]/row2`; `spec = TN/(TN+FP) = t[1,1]/row1`; `err = (off-diag)/total`. Direction matters: this exam codes MM=1 so sensitivity = correct MM identification — Q5b — exams/TMA4268_2024_Exam.Rmd:458-462.
- **Boosting hyperparameter conceptual roles** (filter C) — `n.trees` large + early-stop via CV; `shrinkage` η small → need more trees → better generalization; `interaction.depth` controls tree complexity (depth 1 = stumps; 2 = pairwise interactions) — Q5d — exams/TMA4268_2024_Exam.Rmd:522-538 — compact: large n.trees + small η + shallow trees → safe.
- **Method comparison conclusion: simpler can win** (filter C) — Q5(d)(ii) explicitly: when boosting does NOT beat logistic / GAM, the answer is to prefer the simpler model. The prof rewards "Occam-correct" answers — Q5d(ii) — exams/TMA4268_2024_Exam.Rmd:549.

## Lower-priority but useful

- **Plot-diagnostic mapping (4 panels of `plot(mod)`)** (filter B) — (1) residuals vs fitted → zero mean + homoscedasticity; (2) QQ → normality of errors; (3) scale-location → homoscedasticity in std-residual form; (4) residuals vs leverage → influence (high leverage AND high residual is dangerous) — Q4a(v) — exams/TMA4268_2024_Exam.Rmd:261-264. Prof said QQ plot is the one he'd put on a test.
- **1-SE rule for choosing λ** (filter C) — `lambda.1se` = largest λ whose CV error is within 1 SE of min — gives sparser/simpler model than `lambda.min`. Exam uses 5-fold (not 10) and forces seed for reproducibility — Q4b(iii) — exams/TMA4268_2024_Exam.Rmd:288-296.
- **PCA biplot reading rules** (filter B) — Arrows = loadings; long arrow on PC2 axis = high loading on PC2. Read state position on PC2 from y-coordinate. Population/income/area on PC2 = wealth/size axis; illiteracy near PC1 axis = low PC2 loading. Cumulative variance from scree dots (sum first 3) — Q6e — exams/TMA4268_2024_Exam.Rmd:666-690.
- **Optimization-criterion → method recognition** (filter C) — Pattern-match objectives: `Σ(y−x'β)²` → OLS; `+λΣ|β_j|` → Lasso; cluster within-pair sum / |C_k| → K-means (note the divide by |C_k| variant); region-split SSE → regression tree — Q6d — exams/TMA4268_2024_Exam.Rmd:625-631. Compact equation bank for the cheat sheet.
- **GAM ns() with 5 df per smoother** (filter C) — `ns(x, 5)` consumes 5 df (natural cubic spline). Two such smoothers → 10 df + intercept. Prof says explain "how many df and what functional form" — Q5c(i) — exams/TMA4268_2024_Exam.Rmd:487, 495.
- **PriceDiff collinearity with PriceCH and PriceMM** (filter B) — `PriceDiff = PriceMM − PriceCH` makes a 3-variable model collinear → drop two for interpretable PriceDiff coefficient — Q5a(ii) — exams/TMA4268_2024_Exam.Rmd:398.
- **Regression-tree leaf prediction by walking splits** (filter B) — Each split routes left/right based on threshold; leaf gives mean training response. Calculator-free path-tracing — Q2d — exams/TMA4268_2024_Exam.Rmd:122.
