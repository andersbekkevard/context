# Exam 2025 — Cheat-sheet candidates

## Question summary

The 2025 sit-down (May 19, 2025) is the most recent past exam and exam writer Stefanie Muff signaled this style for 2026. Five problems, ~50P total.

- **Q1 (5P, fill-in)** — Conceptual vocabulary: supervised vs unsupervised, prediction vs inference, parametric models for inference (logistic preferred over KNN etc.), bias-variance, **"variance" = variance of estimated $\hat f$**, Lasso vs ridge (sparsity), and the **prof's signature claim**: Lasso does *not* suffer from **model-selection bias**, unlike AIC. (file:line 44–60)
- **Q2 (8P MC + numeric)** — Mixed bag:
  - 2a: linear regression with **interaction + reference category trap** (the "5.03 kg" main effect is only valid at age = 0). (74–84)
  - 2b: Lasso flexibility framing — Lasso is *less* flexible, accepts bias for variance reduction. (86–102)
  - 2c: **NN parameter count** ($3{\to}4{\to}1$, with biases = 21) + **ReLU forward pass**. (107–135)
  - 2d: **odds ↔ probability** conversions both ways. (137–148)
  - 2e: smoothing-spline $\lambda$ direction-of-effect (smoother, more penalty, lower edf). (150–162)
  - 2f: **PCA hand-calculation** — cumulative PVE, score for a single observation $z_i^\top \phi_1$, total variance = $p$ under standardization, dominant loading interpretation. (165–202)
  - 2g: why non-linear activations are needed. (203–213)
- **Q3 (4P theory)** — 3a: training vs test RSS under a *correctly linear* DGP fitted with extra polynomial flexibility (training always weakly better, test usually worse). 3b: **hand-drawn dendrogram with complete linkage** from a 4×4 distance matrix, fusion heights labeled. (218–255)
- **Q4 (16P regression on Boston)** — Inference vs prediction split: confidence interval on a categorical dummy (`chas`), **F-test (via ANOVA) for a multi-level factor** (`rad`), train/test MSE for OLS, Lasso (10-fold CV, $\lambda_\text{min}$), **boosting with all three tuning parameters justified**, and **GAM df counting for `bs(age, knots=quantile(...,4))` = 7 (K+3)**. (258–440)
- **Q5 (17P classification on Default)** — Logistic regression with `SEX:PAY_0` interaction (**per-group odds multipliers**), sensitivity/specificity at threshold 0.5, **ROC curve axis labeling + interpretation**, KNN at $K=35$, random forest with `mtry ≈ √p` justified, **node-purity importance ranking**, model comparison, and **class-imbalance reflection** (~78% non-default → sensitivity collapses).

## High-priority surfacing

- **Lasso vs AIC: no model-selection bias** (A,C) — Prof's pet talking point appearing in Q1: AIC-minimization *does* suffer from post-selection inference bias; Lasso does not. Not in ISLP this directly. — Q1 — `exams/TMA4268_2025_Exam.Rmd:60` ; mirrored in ISLP §10.6 only as a brief side remark (`wiki/book/10-deeplearning.md:588`). Cheat-sheet line: *"Lasso ≠ AIC-step: Lasso avoids model-selection bias; coefficients from AIC-selected models are biased toward significance."*

- **Interaction main-effect trap** (B) — In a model with `Y ~ age + sex + age:sex`, the `sex` coefficient (e.g. 5.03 kg) is **only** the difference at `age = 0**. Reading it as a global average is wrong. — Q2a — `exams/TMA4268_2025_Exam.Rmd:74-84`, atom at `wiki/concepts/categorical-encoding-and-interactions.md:85-89`. Compact form: *"With $X{:}Z$, $\hat\beta_Z$ = $Z$-effect at $X=0$ only. Compute group-by-group."*

- **Per-group odds multipliers with interaction** (B,C) — For logistic regression with `SEX:PAY_0`: males' odds × $e^{\beta_\text{PAY}}=2.22$ per month, females' × $e^{\beta_\text{PAY}+\beta_\text{SEX:PAY}}=2.57$. Report per group, not as a pooled number. — Q5a(ii) — `exams/TMA4268_2025_Exam.Rmd:482-540`; atom `wiki/concepts/odds-and-log-odds.md:68`. Compact form: *"With interaction: each group has its own $e^{\sum \beta}$ multiplier; sum the relevant $\beta$'s first, then exp."*

- **NN parameter count = $(p{+}1)M + (M{+}1)C$, biases inevitable** (D) — $3{\to}4{\to}1$ gives $(3{+}1)\cdot4 + (4{+}1)\cdot1 = 16+5=21$. **Canonical wrong answer = forgetting biases.** — Q2c(i) — `exams/TMA4268_2025_Exam.Rmd:109-135`, atom `wiki/concepts/nn-parameter-count.md:103-113`. Compact form: *"$(p{+}1)M_1 + (M_1{+}1)M_2 + \dots$ ; every receiving node has a bias; inputs do not."*

- **ReLU forward pass arithmetic** (D) — Linear combo first, then $\max(0,\cdot)$; ReLU of a negative = 0, no leaky behavior. — Q2c(ii) — `exams/TMA4268_2025_Exam.Rmd:117-135`. Compact form: *"$h = \max(0,\, w^\top x + b)$; clip negatives to 0; **not** to $-1$ (that's tanh) and **not** smooth (that's sigmoid)."*

- **Odds ↔ probability both directions** (D) — $p = \text{odds}/(1+\text{odds})$ and $\text{odds} = p/(1-p)$. Memorise both — the exam asks both directions in one question. — Q2d — `exams/TMA4268_2025_Exam.Rmd:137-148`; atom `wiki/concepts/odds-and-log-odds.md:43`. Compact form: *"odds 0.37 → $p\approx 0.27$ ; $p=0.16$ → odds $\approx 0.19$."*

- **Smoothing-spline $\lambda$ direction table** (B) — $\lambda \uparrow$ → smoother / less wiggly / lower effective df / underfit risk; $\lambda \downarrow$ → wigglier / higher edf / overfit risk. — Q2e — `exams/TMA4268_2025_Exam.Rmd:150-162`; atom `wiki/concepts/smoothing-splines.md:140,154`. Compact form: *"$\lambda{\uparrow}$ ⇒ {smoother, more penalty, edf$\downarrow$, underfit}; $\lambda{\to}\infty$ ⇒ edf = 2 (line)."*

- **PCA total variance under standardization = $p$** (D) — When variables are standardized, $\sum \lambda_m = p$, so PVE$_m = \lambda_m / p$. Q2f-style sanity check. — Q2f(6) — `exams/TMA4268_2025_Exam.Rmd:199-202`; atom `wiki/concepts/explained-variance-and-scree-plot.md:36,68`. Compact form: *"Standardized data ⇒ total var = $p$ ⇒ PVE$_m = \lambda_m/p$."*

- **PCA score = $z_i^\top \phi_m$ for one observation** (D) — To get PC$_1$ value for an observation just dot-product the (already standardized) values with the loadings: $0.85{\cdot}1 + 0.2{\cdot}0.5 + 0.2{\cdot}(-0.5) + 0.1{\cdot}(-1) + 0.05{\cdot}0 = 0.75$. — Q2f(3) — `exams/TMA4268_2025_Exam.Rmd:194-196`. Compact form: *"PC$_m(x_i) = \sum_j \phi_{jm} z_{ij}$; no centering step if inputs already standardized."*

- **Training vs test RSS when truth is linear but model is over-flex** (C) — Training RSS of larger model ≤ smaller model **always** (more flexibility); test RSS of larger model **likely higher** due to overfit, but not guaranteed. — Q3a — `exams/TMA4268_2025_Exam.Rmd:220-233`. Compact form: *"Train RSS: bigger model always ≤. Test RSS: usually larger model worse if truth is in smaller, but it's a likelihood, not a theorem."*

- **Complete-linkage dendrogram by hand** (D) — Recipe on 4×4 dissimilarity: find min entry → fuse → recompute set-to-set as **max** of pairwise → repeat. Fusion height = the dissimilarity at fusion. **−1P per labeled mistake**, including missing y-axis. — Q3b — `exams/TMA4268_2025_Exam.Rmd:236-255`; atom `wiki/concepts/hierarchical-clustering.md:67-85`. Compact form: *"Complete linkage: $D(A,B) = \max_{a\in A,b\in B} d(a,b)$; record height at each fusion; y-axis = height."*

- **Quadratic term `I(rm^2)` consumes one extra df → total df = parameter count incl. intercept** (D) — Q4a(ii) answer 18 = intercept + 8 numeric + 7 `rad` dummies (8 levels → 7 dummies) + `I(rm^2)`. — Q4a(ii) — `exams/TMA4268_2025_Exam.Rmd:295`. Compact form: *"Model df = # regression parameters incl. intercept; factor with K levels contributes K−1 dummies."*

- **F-test for a multi-level factor via `anova()`** (B,C) — To test whether a $K$-level factor (`rad`, 8 levels → 7 dummies) is relevant, use the **partial F-test** on the joint null that all $K-1$ dummies are zero, not individual t-tests. The prof said he won't make you *compute* it but **will** ask you to identify it. — Q4a(iv) — `exams/TMA4268_2025_Exam.Rmd:285-303`; atom `wiki/concepts/f-test.md:62,85,109`. Compact form: *"Categorical with $K$ levels ⇒ joint F-test on $K{-}1$ dummies = $H_0$; use `anova()`."*

- **Lasso $\lambda_\text{min}$ vs $\lambda_\text{1se}$ via CV** (B,C) — Standard 10-fold CV recipe; **`set.seed` before CV** for reproducibility; pick $\lambda_\text{min}$ for minimum CV error or $\lambda_\text{1se}$ for the simplest model within one SE. — Q4c — `exams/TMA4268_2025_Exam.Rmd:332-385`. Compact form: *"`cv.glmnet → λ.min (min CV) or λ.1se (simpler within 1 SE)`; standardize internally; report MSE on held-out test."*

- **Boosting tuning parameters must all be justified** (C) — Three knobs: `n.trees` ($M$, a **real** tuning parameter unlike RF), `interaction.depth` (tree depth, controls interaction order), `shrinkage` ($\nu$, learning rate, small e.g. 0.01–0.05). **−0.25P per parameter left unexplained.** — Q4d(i) — `exams/TMA4268_2025_Exam.Rmd:392-405`; atom `wiki/concepts/boosting.md:66,115` + `wiki/concepts/gradient-boosting.md:104-114`. Compact form: *"Boosting: $M$ tunable (too large overfits), $d$ small (1–3), $\nu$ small (0.01–0.1); choose by CV."*

- **GAM df count for `bs(x, knots = quantile(x, c(0.2,0.4,0.6,0.8)))`** (D) — 4 interior knots + cubic = $K+3 = 7$ basis dimensions when intercept is absorbed in the GAM's global intercept. — Q4e(i) — `exams/TMA4268_2025_Exam.Rmd:425-433`; atom `wiki/concepts/regression-splines.md:55,72`. Compact form: *"Cubic regression spline: $K$ knots ⇒ $K+3$ basis dims (excl. intercept). 4 quantile knots ⇒ df = 7."*

- **ROC axes are TPR (y) vs FPR (x), 1-specificity, not specificity** (B) — Easy point lost: y = sensitivity, x = **1 − specificity**, diagonal = random classifier, AUC summarizes across thresholds. — Q5a(iv) — `exams/TMA4268_2025_Exam.Rmd:485-557`; atom `wiki/concepts/roc-auc.md`. Compact form: *"ROC: y = TPR = sens ; x = FPR = 1 − spec ; diag = chance ; AUC ∈ [0.5,1]."*

- **Sensitivity / specificity definitions in problem-specific language** (B) — Prof wants prose, not formulas: "fraction of *true defaulters* the model identifies" (sens), "fraction of *true non-defaulters* the model identifies" (spec). — Q5a(iii) — `exams/TMA4268_2025_Exam.Rmd:484,551-553`. Compact form: *"Sens = TP/(TP+FN) = fraction of actual positives caught; Spec = TN/(TN+FP) = fraction of actual negatives caught. Threshold = 0.5 here."*

- **Class imbalance → high specificity, low sensitivity** (B) — When ~78% are class 0, model defaults to predicting 0 → spec ≈ 1, sens ≈ 0, overall error misleadingly low. Always check the off-diagonal. — Q5d(ii) — `exams/TMA4268_2025_Exam.Rmd:678-684`; atom `wiki/concepts/confusion-matrix.md:65,108` + `wiki/concepts/sensitivity-specificity.md:114`. Compact form: *"Imbalanced data ⇒ model favors majority class ⇒ spec ↑, sens ↓; accuracy lies; report both."*

- **Random forest `mtry ≈ √p` for classification, `p/3` for regression; `ntree` is *not* a tuning parameter** (C) — $p = 22$ → `mtry` ≈ 4–5. Wrong-direction-of-effect mistake: don't pick large `ntree` as if it were a hyperparameter (just use "enough"). — Q5c(i) — `exams/TMA4268_2025_Exam.Rmd:611-618`; atom `wiki/concepts/random-forest.md:88,104,111`. Compact form: *"`mtry`: $\sqrt p$ (class), $p/3$ (reg); `ntree`: 'large enough' (500+); only `mtry` is tuned."*

- **Variable-importance flavors: node-purity vs randomization** (B) — `varImpPlot(..., type=2)` = **MeanDecreaseGini / node-purity-based**; `type=1` = MeanDecreaseAccuracy (randomization). The 2025 stem specifically said "based on node purity" → must use `type=2`. — Q5c(ii) — `exams/TMA4268_2025_Exam.Rmd:603-639`; atom `wiki/concepts/variable-importance.md:42,57,96`. Compact form: *"Node-purity importance = total Gini/RSS decrease from splits on $X_j$ = `type=2` in `varImpPlot`."*

## Lower-priority but useful

- **Lasso flexibility direction** (B) — Lasso is *less* flexible than OLS (shrinkage = constraint). Many students reflexively say "more flexible" because of "more sophisticated." — Q2b — `exams/TMA4268_2025_Exam.Rmd:86-102`; atom `wiki/concepts/lasso.md`.
- **Lasso can fail to improve over OLS** (C) — In Q4c the test MSE for Lasso was *not* better than OLS, and **no coefficients were zeroed** — interpretation: this dataset has mostly real signal, Lasso has nothing to shrink. Be ready to give this interpretation. — Q4c(ii) — `exams/TMA4268_2025_Exam.Rmd:384-385`.
- **CV `set.seed` before randomized step** — Reproducibility requirement, half-point lost otherwise. (332–334)
- **"Why nonlinear activations"** (D) — Only correct answer: to approximate non-linear functions (universal approximation). Faster training and parameter reduction are distractors. — Q2g — `exams/TMA4268_2025_Exam.Rmd:203-213`; atom `wiki/concepts/universal-approximation.md`.
- **`pairs(...)` / `summary(...)` / `str(...)` as exploration ritual** — Prof signals as good practice but not graded. (272–278, 476)
- **Confidence interval reporting** — Effect size *and* CI required, in the *original* units (× 1000 USD for `medv`). (282–297)
- **Comparing four methods** (C) — Q4 sequence (OLS → Lasso → boosting → GAM) is the canonical "ladder" of flexibility; the *winner* in Q4 was boosting, second GAM, then OLS, then Lasso. Use this ranking as a heuristic when asked "which would you pick." — Q4d(ii), Q4e(ii) — `exams/TMA4268_2025_Exam.Rmd:412, 438-440`.
- **Three-way model comparison table** (logistic / KNN / RF on imbalanced data): RF wins on both error rate and sensitivity. Generic exam pattern for picking a classifier under imbalance. — Q5d — `exams/TMA4268_2025_Exam.Rmd:664-674`.
