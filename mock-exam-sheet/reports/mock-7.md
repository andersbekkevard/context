- **LOOCV: lower bias but higher variance than k-fold** (B) — counterintuitive because LOOCV training sets overlap almost completely → correlated fold errors → high variance of the average — Q2(b)(ii) — `mock-exam-7-solution.tex:98-101` — *Bias↓ / variance↑ is opposite of typical bias-variance pattern.*
- **The selection-leakage CV trap (filter-then-CV)** (B, C) — ranking p=5000 features by marginal cor(x,y) BEFORE CV leaks holdout-fold information; CV error biased way below Bayes 50% — Q2(b)(iii) — `mock-exam-7-solution.tex:102-107` — *Variable selection must be INSIDE each CV iteration. - **Nested CV: inner = selection, outer = assessment** (A, C) — the bias of naive `min_θ CV_k(θ)` reported as test error — Q1(10), Q2(b)(iv), Q3(b) — `mock-exam-7-solution.tex:108-111, 409-413` — *min over noisy grid favors θ_t lucky on these folds → systematic downward bias.*
- **AdaBoost α_m formula and the negative-α flip** (A, D) — α_m = log((1−err_m)/err_m); err > 0.5 → α < 0 → ensemble INVERTS a worse-than-chance vote — Q2(d)(iv), Q3(c)(ii) — `mock-exam-7-solution.tex:156-159` — *α_1 = ln((1−err)/err) with ln(1.5) ≈ 0.405 for err=0.4.*

- **Boosting reduces BIAS (not variance like bagging/RF)** (B, C) — sequential residual-fitting; trees NOT bootstrapped, NOT averaged — Q2(d)(ii) — `mock-exam-7-solution.tex:146-151` — *Bagging/RF reduce variance via independent-replicate averaging; boosting reduces bias via sequential correction.*
